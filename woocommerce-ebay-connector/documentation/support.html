Support & Assistance

We are dedicated to ensuring your WooCommerce and eBay integration runs smoothly and reliably.

Webkul Helpdesk & Ticket System

For technical assistance, bug reports, or integration questions regarding WooCommerce eBay Connector:

  • Official Support Portal: Visit the Webkul Helpdesk or Webkul Ticket System.
  • Submit a Ticket: Provide your order ID, WordPress/WooCommerce version numbers, PHP error logs, and detailed steps to reproduce the issue.
  • Direct Email: support@webkul.com
  • Response Window: Our dedicated support engineers typically respond within 24–48 business hours (Monday through Friday).

Before Contacting Support

To help our technical team diagnose and resolve your inquiry as quickly as possible, please gather the following store information:

Required Information Checklist

InformationWhere to Find It
WordPress VersionWordPress Dashboard → Updates
WooCommerce VersionWooCommerce → Status → System Status
Plugin VersionPlugins → Installed Plugins (WooCommerce eBay Connector)
PHP VersionWooCommerce → Status → System Status
Active eBay Marketplace SiteWC Ebay Connector → Manage Account → Settings (US, UK, DE, etc.)
Server Error Logs/wp-content/debug.log or WooCommerce → Status → Logs

How to Enable WordPress Debug Mode

If you encounter a blank screen, 500 server error, or unexpected sync termination, temporarily enable debugging in your wp-config.php file:

// Add to wp-config.php before "/* That's all, stop editing! */"
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );

Error entries will be appended to /wp-content/debug.log, which you can attach securely to your support ticket.

Reporting Bugs

Found an unexpected issue? Submit a ticket using the following structured format to expedite review:

**Summary:** Brief description of the issue

**Steps to Reproduce:**
1. Navigate to WC Ebay Connector → ...
2. Select ...
3. Click ...

**Expected Result:** What should happen
**Actual Result:** What happens instead (include exact error message)

**Environment:**
- WordPress: 6.8
- WooCommerce: 10.5
- Plugin Version: 5.0.0
- PHP: 8.2

Support Coverage & Policies

What Is Covered Under Included Support

  • ✅ Bug fixes, patches, and verified defect resolutions.
  • ✅ Assistance with module installation, activation, and initial setup.
  • ✅ Explanations regarding connector settings, mapping rules, and workflows.
  • ✅ Compatibility updates for major WordPress and WooCommerce releases.

What Is Not Covered

  • ❌ Custom theme styling or third-party checkout/multivendor plugin conflicts.
  • ❌ Web server administration, PHP compilation, or reverse-proxy server misconfigurations.
  • ❌ Custom code modifications or feature development beyond the core plugin.
