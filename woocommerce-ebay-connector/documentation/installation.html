Installation & System Requirements

This guide outlines the system prerequisites, server configuration, and installation steps required to run WooCommerce eBay Connector.

System Requirements

Before installing the plugin, ensure your hosting environment meets the following specifications:

ComponentMinimum RequiredRecommended
WordPress6.7+6.8 or 7.0+
WooCommerce10.0+10.5+ (tested up to 11.2)
PHP Version7.48.1, 8.2, 8.3, or 8.5
PHP ExtensionscURL, OpenSSL, JSON, mbstringSOAP (optional, plugin includes native HTTP fallback)
DatabaseMySQL 5.7+ / MariaDB 10.3+MySQL 8.0+
SSL / HTTPSRequiredRequired for eBay OAuth and API security
Memory Limit256MB512MB for high-volume catalogs

Native HTTP Transport

While earlier versions required the PHP SOAP extension, version 5.0.0 includes a native HTTP transport fallback. The connector operates reliably even on hosting providers where SoapClient or SoapServer is disabled.

Installation via WordPress Admin

  1. Log in to your WordPress Administration Dashboard (wp-admin).
  2. Navigate to Plugins → Add New Plugin.
  3. Click the Upload Plugin button at the top of the screen.
  4. Select the plugin ZIP file (wp-woocommerce-ebay-connector.zip) and click Install Now.
  5. Once uploaded, click Activate Plugin.

Installation via FTP / SSH

  1. Extract the downloaded wp-woocommerce-ebay-connector.zip archive on your local computer.
  2. Using an FTP client or SSH, upload the wp-woocommerce-ebay-connector folder to your server's /wp-content/plugins/ directory.
  3. Open your WordPress dashboard, navigate to Plugins → Installed Plugins, locate WooCommerce eBay Connector, and click Activate.

License Activation

After activating the plugin, you must validate your purchase license to unlock automatic updates and support:

  1. Navigate to Webkul WC Addon → Settings in your WordPress admin sidebar.
  2. The interactive License Activation Wizard will appear.
  3. Enter your Order ID / Purchase Code and your registered email address.
  4. Click Activate License.

License Validator Guide

For step-by-step assistance, renewal details, or troubleshooting license verification on staging vs. production domains, visit the official Webkul License Activation Guide.

Post-Activation Verification

Once activated, the connector integrates automatically with your WordPress environment:

  • A new menu item appears under Webkul WC Addons → WC Ebay Connector (admin.php?page=ebay-connector).
  • Database tables (prefixed with {$wpdb->prefix}woocommerce_ebay_*, including woocommerce_ebay_account, woocommerce_ebay_category_map, woocommerce_ebay_product_map, woocommerce_ebay_order_map, woocommerce_ebay_listing_template, woocommerce_ebay_price_rule, and background queue tables) are created automatically with proper schema versions.
  • Background tasks register with Action Scheduler (scheduled recurring imports every 15 minutes).
  • If no eBay accounts are configured, the connector prompts you to launch the Interactive Setup Wizard.

Module Translation

The WooCommerce eBay Connector is fully localization-ready and supports multi-language translation for international stores:

  • Translation Templates: The plugin includes standard .pot files located in the languages/ folder.
  • Translating with Loco Translate / Poedit:
    1. Install the free Loco Translate plugin from the WordPress repository, or download desktop Poedit.
    2. Navigate to Loco Translate → Plugins → WooCommerce eBay Connector.
    3. Select your target store language (e.g., German, French, Spanish, Italian, Japanese).
    4. Translate the strings into your language and click Save.
  • For detailed instructions on creating custom .po and .mo files, refer to the Webkul WooCommerce Plugin Translation Guide.
