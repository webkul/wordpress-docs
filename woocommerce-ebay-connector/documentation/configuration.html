Account Settings & Configuration

Each connected eBay account maintains its own independent configuration tab accessible via WC Ebay Connector → Manage Account → Settings.

1. General Settings

The General sub-tab controls core sync behavior, default product statuses, duplicate SKU prevention, image download workflows, and automated background jobs.

Background Image Processing

For catalogs with large image galleries or hundreds of items, setting Product Image Import Method to In the Background ensures rapid product catalog import while image files download asynchronously in queue batches.

All products should ideally be synchronized or mapped before order imports occur. If an unmapped item is purchased on eBay, enabling Auto Create Missing Order Products ensures the order imports without interruption.

2. Shipping & Listing Policies

The Shipping/Listing sub-tab configures dispatch rules, domestic/international carriers, and per-product shipping settings.

  • eBay Per-Product Shipping: Toggle whether WooCommerce calculates shipping using eBay product shipping metadata.
  • Dispatch / Handling Time: Number of business days before the order is marked dispatched (1, 2, 3, 5, 10 days).
  • Shipping Service Type: Choose Flat, Calculated, or Freight.
  • Domestic & International Shipping Services: Select primary and secondary carriers (e.g., USPS Priority Mail, FedEx, UPS, DHL).
  • Free Shipping & Local Pickup: Enable checkboxes to offer free domestic delivery or in-store collection options.

3. Return Policy Settings

Configure the formal return policies required by eBay for merchant listings.

  • Returns Accepted: Choose ReturnsAccepted or ReturnsNotAccepted.
  • Return Period: Select standard return eligibility windows (14 Days, 30 Days, 60 Days).
  • Refund Method: Specify how returns are reimbursed (MoneyBack, Exchange, Replacement).
  • Shipping Cost Paid By: Specify whether Buyer or Seller covers return freight fees.
  • Return Policy Description: Detailed policy text visible to eBay shoppers outlining return conditions, packaging rules, and restocking guidelines.

4. Price Rules

The Price Rules sub-tab enables automatic markups or discounts on imported or exported products.

  • Rule Application: Apply to Import (eBay → WooCommerce), Export (WooCommerce → eBay), or both.
  • Calculation Type:
    • Percentage: Add or subtract a percentage markup (e.g., +15% to offset eBay final value fees).
    • Fixed Amount: Add or subtract a flat monetary sum (e.g., +$5.00).
  • Price Range Bounds: Restrict rules to products within specific minimum and maximum price thresholds.

5. Real-Time Sync Settings

The Real Time Sync sub-tab (sub-tab=sync_sub_tab) regulates live bidirectional events between WooCommerce and eBay:

  • Bidirectional Event Toggles: Independent master switches for eBay to WooCommerce Real Time Sync and WooCommerce to eBay Real Time Sync.
  • Real-Time Order Import: Toggle automatic order creation when eBay transmits an AuctionCheckoutComplete webhook notification.
  • Granular Field-Level Update Selection: Choose exactly which product attributes synchronize when an item is revised, protecting customized descriptions or pricing:
    • eBay → WooCommerce: Checkbox selection for Title, Price, Quantity, Description, Image, and Weight.
    • WooCommerce → eBay: Checkbox selection for Title, StartPrice, Quantity, and Description.
  • End Item & Trashed Product Lifecycle Automation:
    • When an eBay Listing Ends (ebay_to_woo_item_end): Choose whether the corresponding WooCommerce product is moved to Trash, set to Draft, or left unchanged.
    • When a WooCommerce Product is Trashed (woo_to_ebay_item_end): Automatically dispatches an EndItem API call to close the active eBay listing and prevent sales of discontinued inventory.
  • Admin Email Alerts: Enable email notifications to receive alerts when specific eBay sync events occur.

6. eBay Notifications Event Rules

The Ebay Notifications sub-tab (sub-tab=ebay_notification_sub_tab) provides a dedicated monitoring table for all marketplace webhook events supported by the connector's notification listener:

eBay EventDescriptionAction Taken
ItemListedTriggered when a new item is published on eBay.Logs event or creates product if real-time catalog sync is active.
ItemRevisedTriggered when listing details change on eBay.Updates mapped WooCommerce product fields selected under sync settings.
ItemSoldTriggered when an item sells on eBay.Decrements local WooCommerce catalog stock in real time.
ItemClosedTriggered when an eBay listing ends or is cancelled.Applies configured end-item rule (Trash, Draft, or None).
FixedPriceTransactionTriggered on fixed-price sales.Ingests transaction and reserves store stock.
AuctionCheckoutCompleteTriggered when a buyer completes payment.Triggers instant real-time order import when enabled.

7. Exclude Product Sync

The Exclude Product Sync sub-tab (sub-tab=exclude_product_sub_tab) prevents designated catalog items from being synchronized between WooCommerce and eBay.

  • Import Exclusion List: Enter specific eBay Item IDs that should never be pulled into WooCommerce.
  • Export Exclusion List: Select WooCommerce products that must remain exclusive to your WordPress store and never be listed on eBay.
