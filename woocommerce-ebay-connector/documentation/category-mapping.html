Category Management & Mapping

Before publishing products or synchronizing catalog inventory, you must import eBay categories and link them to your WooCommerce product taxonomy.

1. Category Management (tab=manage-category)

The Categories tab displays all categories imported from your eBay seller store or eBay marketplace site.

Importing eBay Categories

  1. Open WC Ebay Connector → Manage Account → Categories.
  2. Click the Import Categories button.
  3. The connector communicates with the eBay Taxonomy API to retrieve leaf categories, parent levels, and store categories.
  4. Imported categories are indexed in the local database with their unique eBay Category ID, name, parent path, and leaf indicator.

2. Category Mapping List (tab=manage-category-mapping)

The Category Mapping tab displays all existing pairings between WooCommerce categories and eBay categories.

  • WooCommerce Category: Store category name and internal term ID.
  • eBay Category: Mapped eBay category name and unique eBay Category ID.
  • Category Type: Indicates whether the pairing applies to Primary marketplace categories or eBay StoreFront / Custom categories.
  • Actions: Edit or Delete existing mappings.
  • Map Category Button: Click the primary Map Category button beside the search box to launch the dedicated multi-row mapping workspace (view=map).

3. The Category Mapping Workspace (view=map)

Clicking Map Category opens the full-screen interactive mapping interface.

Step-by-Step Category Selection

  1. Choose Category Mapping Type:
    • Map eBay Primary Categories: Pairs store categories with official eBay marketplace categories. These determine where items appear in eBay search and which item specifics are required.
    • Map eBay StoreFront / Custom Categories: Pairs store categories with custom departmental categories defined in your eBay Store subscription.
  2. Select the WooCommerce Category:
    • Select your store category from the left cascading dropdown. If your WooCommerce taxonomy includes parent-child subcategories, drill down level by level until reaching the target subcategory.
  3. Drill Down to the eBay Leaf Category:
    • Select the top-level eBay category (e.g., Collectibles, Computers, Clothing).
    • Additional dependent dropdown menus automatically load in real time via AJAX as you navigate deeper into eBay's category taxonomy hierarchy.
    • Continue selecting child categories until you reach a leaf category (a category with no further sub-branches). The connector validates leaf status to ensure eBay accepts product listings in that category.

4. Batch Mapping: Mapping Multiple Categories at Once

Merchants with extensive catalogs do not need to save and reload the page for each category pair. The workspace supports mapping several categories simultaneously.

How to Map Multiple Categories in One Session

  1. Add Additional Rows:
    • Click the Add another row (+) button beneath the mapping list.
    • A new numbered row appears immediately with independent cascading selectors.
  2. Configure Each Category Pair:
    • In each row, select your WooCommerce category on the left and drill down to the corresponding eBay leaf category on the right.
  3. Row Validation & Duplicate Prevention:
    • The connector automatically checks for duplicate WooCommerce category selections across rows. If you accidentally select the same WooCommerce category twice for the same mapping type, a clear field-level error alerts you before saving.
  4. Remove Unneeded Rows:
    • Click the remove button (✕) on any row to discard an unneeded pairing before saving.

5. Saving Mappings & Real-Time Progress Bar

Once all category pairs are configured, click Save Mappings at the bottom of the workspace.

What Happens During the Save Process

  1. Comprehensive Validation:
    • The system validates that both sides of every active row are drilled down to a valid leaf category.
  2. Live Animated Progress Notification:
    • An active progress banner (#fmebay-map-progress) appears at the top of the workspace.
    • Progress Counter: Displays Mapping category X of Y….
    • Active Pair Details: Displays the current WooCommerce category and target eBay category being processed (e.g., Clothing → Dolls & Bears).
    • Progress Bar: An animated bar advances proportionally from 0% to 100% as each row is saved.
  3. Automatic Item Specifics & Terms Import:
    • As each eBay category is paired, the connector queries eBay's Taxonomy API for all required and recommended item specifics (attributes and allowed term values) associated with that category.
    • These attribute terms are automatically imported into WooCommerce in background chunks, saving you from having to manually configure category attributes later.
  4. Row-by-Row Status Indicators:
    • Each row transitions dynamically from Saving… (with spinner) to Saved (with a green checkmark badge).
  5. Completion & Redirection:
    • Upon completing all rows, the progress bar marks Done!, and the workspace redirects back to the Category Mapping list displaying a success confirmation notice with the total count of newly saved mappings.

6. eBay Category Conditions & Specifications

Once a WooCommerce category is mapped to an eBay leaf category, the connector automatically activates category-specific metadata across your store:

eBay Category Conditions

On the WooCommerce add/edit product page, products assigned to a mapped category will dynamically display the eBay Category Condition field:

  • The condition options (e.g., New, New with tags, New without tags, Refurbished, Used - Excellent, For parts or not working) are fetched directly from the mapped eBay category.
  • Selecting the appropriate condition ensures that exported listings meet eBay's condition requirements for that category.

eBay Category Specifications (Global Attributes)

Mapped categories also enable eBay Category Specifications, which are imported as global WooCommerce attributes:

  • Navigate to Products → Attributes in your WordPress dashboard to review imported specifications.
  • Attributes follow the standardized nomenclature: Attribute name [mapped category name].
  • Supplying values for mandatory category specifications ensures 100% compliance with eBay listing requirements and prevents rejection errors during export.

7. Automatic Category Mapping (Enable Automapping)

If the Enable Automapping toggle is activated in General Settings:

  • When importing products from eBay, the connector checks whether the eBay category matches an existing WooCommerce category.
  • If a match is found, products are automatically assigned to that category without requiring manual intervention.
  • This streamlines multi-category catalog imports and keeps incoming inventory organized.
