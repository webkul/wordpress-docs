FAQs & Troubleshooting

Find answers to common questions and solutions to frequent setup or synchronization issues.

Frequently Asked Questions

Does the connector support variable products?

Yes. Both simple and variable products can be imported from eBay into WooCommerce and exported from WooCommerce to eBay, including variations, specific SKUs, prices, stock counts, and variation-level image sets.

Can I connect multiple eBay seller accounts?

Yes. The connector includes a multi-account hub. You can connect multiple eBay accounts across different international marketplace sites (e.g., US, UK, Australia, Germany) and manage their settings, categories, and orders independently from a single WordPress dashboard.

How does the connector handle eBay API rate limits?

In version 5.0.0, the connector actively monitors remaining API calls. If the daily threshold approaches limit boundaries, import tasks pause automatically to protect your account. The queue displays remaining calls and reset time, and resumes automatically once calls reset (with a manual Resume Now button).

Do I need the PHP SOAP extension installed on my server?

No. While earlier versions required php-soap, version 5.0.0 includes a native HTTP transport fallback. The plugin runs seamlessly on cloud hosting or shared servers where SoapClient and SoapServer are not enabled.

Will imported eBay orders deduct inventory in WooCommerce?

Yes. When an order is pulled from eBay, WooCommerce decrements the inventory for each matching product line item, ensuring stock remains uniform across both WooCommerce and eBay.

Why are my product images not showing on eBay?

eBay enforces strict image hosting requirements. If images fail to display on eBay:

  1. Resolution: Images must be at least 500 pixels on the longest side (at least 1000px recommended for eBay's zoom feature).
  2. Format: eBay accepts JPEG, PNG, TIFF, BMP, and GIF formats.
  3. HTTPS Accessibility: Product image URLs must be publicly accessible over secure HTTPS. Staging sites behind basic authentication or firewalls cannot deliver images to eBay.
  4. Gallery Limit: eBay allows up to 12 images per listing.

Can I set custom prices for eBay that differ from my WooCommerce store?

Yes. You have two flexible options:

  • Price Rules: Set automatic percentage or fixed markups/markdowns under WC Ebay Connector → Manage Account → Settings → Price Rules (e.g., +15% to offset eBay selling fees).
  • Per-Product Price Overrides: Set a custom price directly for any individual item in the Edit eBay Listing workspace.

How do order statuses map between eBay and WooCommerce?

When customer orders sync from eBay, statuses correspond as follows:

eBay Order StatusWooCommerce Order StatusDescription
Active / CheckoutCompleteProcessingOrder is paid and ready for packing and fulfillment.
CompletedCompletedOrder has been dispatched with tracking or marked fulfilled.
CancelledCancelledOrder was cancelled by buyer or seller on eBay.
RefundedRefundedPayment was returned to the customer.

Can I connect a single eBay account to multiple WooCommerce stores?

No. An eBay account should only be connected to one WooCommerce installation. Connecting a single eBay seller account to multiple independent stores causes webhook conflicts, duplicated order imports, and stock collisions. However, you can connect multiple eBay accounts to a single WooCommerce store using the multi-account hub.

How is the plugin licensed and what happens when support expires?

The plugin is sold as a one-time purchase lifetime license for a single WordPress installation with no monthly subscription or per-order transaction fees. Your license includes free lifetime minor updates and 3 months of technical support. If the support period ends, the plugin remains 100% functional on your store indefinitely.

Where can I find error logs and debug information?

  • Action Scheduler Queues: Navigate to Tools → Scheduled Actions (or WooCommerce → Status → Scheduled Actions) and filter by group fmebay.
  • System Logs: Navigate to WooCommerce → Status → Logs and select fmebay-* log files from the dropdown to review API payloads, HTTP status codes, and error traces.

Common Issues & Troubleshooting

1. "eBay API error: Invalid credentials or token expired"

  • Cause: The eBay Auth Token has expired or the App ID / Dev ID / Cert ID credentials are incorrect.
  • Resolution:
    1. Go to WC Ebay Connector → Account List.
    2. Click Edit on the affected account.
    3. Generate a fresh user token from the eBay Developer Portal and paste it into the credentials field.
    4. Click Verify Credentials and save changes.

2. "Required item specifics missing for category"

  • Cause: eBay mandates certain attributes (such as Brand, Size, or MPN) for specific leaf categories before accepting a listing.
  • Resolution:
    1. Ensure the store category is mapped to a valid eBay leaf category in Category Mapping, which automatically imports required category attribute terms.
    2. Navigate to WC Ebay Connector → Manage Account → Export Products.
    3. Click eBay Setup on the product row and open the Item Specifics tab.
    4. Enter the required attribute values (e.g., Brand, MPN) or click Add Specific to supply custom attributes before queueing the item for export.

3. Orders not importing automatically

  • Cause: Action Scheduler or WP-Cron is not executing regularly on your server.
  • Resolution:
    1. Check WooCommerce → Status → Scheduled Actions.
    2. Search for fmebay_import_order_cron and verify the next scheduled run.
    3. Ensure your server has a native system cron job configured (calling wp-cron.php every 5–15 minutes) rather than relying exclusively on WordPress page visitor traffic.

4. Background image import paused or slow

  • Cause: Large image sizes or slow eBay image server responses.
  • Resolution:
    1. The connector handles product data first and image processing in a dedicated background queue.
    2. Check the administrative notification banner at the top of the account screen to see remaining image counts.
    3. If paused, click Resume Background Process.
