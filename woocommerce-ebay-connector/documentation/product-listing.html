Product Listing & Import Management

The Products tab (WC Ebay Connector → Manage Account → Products) serves as the management center for items imported from your eBay seller account into WooCommerce.

1. Product Table Overview

The table displays all imported products and their current synchronization status:

  • Thumbnail: Featured image synchronized from the eBay listing.
  • Product Title: Product name linked to the WooCommerce product edit screen.
  • WooCommerce Product ID: Local WordPress post ID.
  • eBay Item ID: Global 12-digit eBay marketplace item identifier.
  • Product Type: Simple or Variable product indicator.
  • Stock & Regular Price: Real-time stock count and price in store currency.
  • Sync Status: Indicator showing whether the item is active, updated, or excluded.

2. Importing Products from eBay

Merchants can import products through several flexible methods:

  1. Import All Active Listings:
    • Click the Import Products button.
    • The connector queries eBay's Trading API (GetMyeBaySelling) to retrieve all active items.
    • Products are queued in the background and processed in manageable batches.
  2. Import Products Date-Wise:
    • Specify a Start Date and End Date range.
    • Retrieves only items created or revised on eBay within the specified window.
  3. Import by eBay Product IDs:
    • Provide a comma-separated list of specific 12-digit eBay Item IDs.
    • The connector fetches only those individual items, ideal for targeted catalog updates or re-importing single listings.
  4. Background Image Processing:
    • Product text and pricing are created immediately, while high-resolution images import asynchronously in the background.
    • A live progress notice displays remaining images, with pause and resume controls.

Category Assignment Rules During Import

When an eBay listing is imported, the connector determines its WooCommerce category using the following priority hierarchy:

  1. Existing Category Mapping: If the eBay category has been mapped in Category Mapping, the item is placed into the corresponding WooCommerce category.
  2. Automapping: If Enable Automapping is active in General Settings, the connector assigns the item to a WooCommerce category sharing the same name as the eBay category.
  3. Default Category Fallback: If no mapping or matching category exists, the item is placed into the store's Choose Default Category configured under settings.

3. Updating Products from eBay

When listings are modified directly on eBay:

  • Select products using the row checkboxes and choose Update from eBay from the bulk actions dropdown.
  • Alternatively, click the Update action on an individual product row.
  • The update pulls revised variation attributes, secondary images, item condition descriptions, and updated shipping rates into WooCommerce.

4. Rate-Limit Auto-Pause & Resume

To protect your eBay seller account from API throttling:

  • The connector actively monitors daily API consumption (RemainingCallCount).
  • If call limits approach threshold boundaries, the background import queue automatically pauses.
  • An administrative banner notifies you of the reset window and provides a Resume Now override button once new calls become available.
  • You can inspect your live API usage, tracked calls, and reset timers at any time via the Real-Time eBay API Limits Monitor on your account card.

5. Supported Product Types & Compatibility Matrix

WooCommerce eBay Connector supports full bidirectional synchronization for standard and complex product types:

Product TypeImport (eBay → WooCommerce)Export (WooCommerce → eBay)Notes
Simple Products✅✅Standard single-SKU catalog items.
Variable Products✅✅Multi-variation items with per-variation SKUs, attributes, stock, prices, and images.
Auction-Type Products✅❌Imported into WooCommerce as Simple products. Creating or bidding on auctions from WooCommerce is not supported.
Virtual / Downloadable Products❌❌eBay requires physical shipping tracking for consumer seller protections.

6. Synchronized Product Information

The following catalog attributes are synchronized between WooCommerce and eBay:

  • SKU & Product Identifiers: Store SKU, UPC, EAN, ISBN, and MPN.
  • Product Title & Subtitle: Main listing title and promotional subtitles.
  • Description & HTML Templates: Standard description or rendered visual listing template.
  • Inventory & Stock Levels: Real-time stock counts with two-way stock deduction.
  • Product Images & Galleries: Featured thumbnail and full gallery photo carousels.
  • Taxonomy Categories: Primary category and eBay StoreFront / custom categories.
  • Prices & Currency: Base prices, price markup/markdown rules, and currency conversion.
  • eBay Conditions & Specifics: Item condition ID, condition notes, and leaf category attributes.
