eBay Account Setup & Developer Credentials

To integrate WooCommerce with eBay, the store administrator must obtain API credentials from the eBay Developers Program and link their seller account.

This guide covers:

  1. How to Obtain eBay Developer Credentials (Creating an App, Keysets, User Tokens, and Sandbox accounts)
  2. Connecting Your Account in WooCommerce (Using the Interactive Setup Wizard or Manual Configuration)
  3. Multi-Account Management & Real-Time API Limits Monitoring

1. How to Obtain eBay Developer Credentials

To authenticate API requests, you need four key credentials from eBay: App ID (Client ID), Dev ID, Cert ID (Client Secret), and an Auth / User Token.

Step 1: Join the eBay Developers Program

  1. Navigate to the eBay Developer Portal.
  2. Click Sign-in / Join in the upper right corner to register for a free developer account or sign in with your existing eBay account.

  1. Complete the registration form and accept the developer agreement.

Step 2: Create an Application & Generate Keys

  1. Once logged in, go to the Application Keys dashboard.
  2. Enter an App Name for your integration (e.g. MyWooCommerceStore).
  3. Choose the operating environment for your keyset:
    • Production (Live): Required for live selling, real catalog exports, and order processing.
    • Sandbox: For testing without listing fees or live buyer interactions.
  4. Click Create a keyset to generate your developer keys.

Note

The application name is not saved until keys are generated.

Your keyset provides:

  • App ID (Client ID): Identifies your application to eBay.
  • Dev ID: Unique developer identifier assigned to your account.
  • Cert ID (Client Secret): Private certificate key used for authentication.

Step 3: Generate User Token & Grant Consent

A User Token authorizes the connector application to interact with your specific eBay seller account.

  1. Under the Production or Sandbox keyset on the Application Keys page, click the User Tokens link beside your App ID.

  1. Click Sign in to Production (or Sign in to Sandbox if configuring a test environment).

Production Account Required

The eBay Sandbox account is for testing purposes only. For real product exports and order synchronization, a Production (Live) account is required.

  1. Log in using your eBay seller account credentials and click the Agree button on the authorization consent screen.

  1. Once authorized, eBay generates your long-lived Auth Token. Copy this token; you will paste it into the connector settings.

Step 4: (Optional) Sandbox Account Setup

If you prefer to test your catalog synchronization and order processing in a simulated sandbox environment:

  1. Click on the Register a new Sandbox user link in the developer portal.
  2. Complete the Sandbox user registration form and accept the API License Agreement.

  1. Review the sandbox guidelines and note your test merchant credentials.

  1. Log in to sandbox.ebay.com using your test Sandbox credentials to verify the account is active.

2. Connecting Your Account in WooCommerce

WooCommerce eBay Connector supports two ways to link your eBay account: the guided Interactive Setup Wizard or Manual Configuration.

Option A: The Interactive Setup Wizard

The setup wizard automatically launches on your first visit to Webkul WC Addons → WC Ebay Connector if no accounts exist. You can also re-launch it anytime from the admin header drawer or by visiting admin.php?page=fmebay-setup&from_help_tab=1.

  1. Step 1: Welcome & Prerequisites: Reviews required permissions and keys. Click Let's Go!.
  2. Step 2: API Keys Configuration:
    • Select Production or Sandbox.
    • Paste your App ID, Dev ID, Cert ID, and RuName.

  1. Step 3: eBay User Token:
    • Paste your generated Auth Token.
    • Click Verify Credentials to perform a live handshake with eBay's API.
  2. Step 4: Store Information & Defaults:
    • Store Name: Internal reference identifier (e.g. "US Flagship Store").
    • eBay Site ID: Marketplace country/region (e.g., US, UK, Australia, Germany, etc.).
    • Currency: Primary currency matching the selected eBay site.
    • Default Category: Fallback WooCommerce catalog category for imported items.
  3. Step 5: Ready: Confirms the account is connected and directs you to the Account List or Category Mapping.

Option B: Adding an Account Manually

If you skip the wizard or need to connect additional eBay accounts to your multi-account hub:

  1. Navigate to Webkul WC Addons → WC Ebay Connector.
  2. Click the Add Account (or Add New) button.

  1. Fill in the configuration fields:
FieldDescription
Store NameAn internal descriptive label for this eBay account in WooCommerce.
Select Global SiteThe target eBay marketplace region (e.g., US, UK, Australia, Germany, Motors, etc.).
eBay User IDYour eBay seller username.
Developer IDThe Dev ID from your eBay Developer Portal keyset.
Application IDThe App ID (Client ID) from your eBay Developer Portal keyset.
Certification IDThe Cert ID (Client Secret) from your eBay Developer Portal keyset.
eBay Application TokenThe User Auth Token generated during account authorization.
Account TypeSelect Production for real marketplace trading or Sandbox for testing.
  1. Click Save & Test Connection. The connector validates the credentials against eBay's Trading and REST APIs.

3. Multi-Account Management

The Account List displays all connected accounts in responsive cards:

From each account card, you can:

  • Check API Limits: Query eBay API quota consumption in real time without incurring background call overhead on standard pageviews.
  • Manage Account: Open the account workspace containing all tabs for categories, products, orders, templates, and settings.
  • Edit Account: Update keys, store name, or re-verify tokens without re-entering unchanged credentials.
  • Delete Account: Remove an account and its associated mapping metadata with modal confirmation.

4. Real-Time eBay API Limits Monitor

eBay enforces rolling 24-hour rate limits per application key set across its REST and Trading APIs. To help merchants monitor quota consumption and avoid unexpected API throttling, WooCommerce eBay Connector provides an on-demand Check API limits tool directly on each account card in the account list.

Clicking Check API limits on an account (such as production account Webkul Dev, ID #14) opens the live limits inspection dialog:

Key Capabilities of the API Limits Monitor

  1. On-Demand Quota Queries:
    • Querying limits happens exclusively on user click (admin-ajax.php?action=fm_ebay_check_api_limits), ensuring normal admin pageviews consume zero API quota calls.
  2. Production vs. Sandbox Reporting:
    • Production Accounts (e.g. Account #14): Fetches live rate limit metrics across all 140+ tracked eBay API endpoints, including Trading API calls (AddItem, AddFixedPriceItem, ReviseItem, GetOrders), Commerce Taxonomy, and Developer Analytics.
    • Sandbox Accounts: eBay's Developer Analytics API does not track Trading API calls for sandbox keys; the modal automatically displays an informative notice explaining this platform limitation while continuing to report other REST endpoints.
  3. Connector-Specific Call Highlighting:
    • Endpoints utilized by the connector (Trading API, Commerce Taxonomy for category trees, and Developer Analytics) are badged with Used by this connector and pinned to the top of the table for immediate visibility.
  4. Summary Metrics & Filtering:
    • Summary Counter: Displays counts of total tracked calls (141), calls currently In use, endpoints Running low (<20% remaining), and endpoints Used up (0 remaining).
    • Status Tabs: Quickly filter between In use, Running low, and All.
    • Live Search: Instant text search filter (e.g., search AddItem or Order) to find exact endpoints without scrolling through the 140+ resource catalog.
  5. Visual Capacity Meters & Countdown:
    • Usage Meter: Visual color-coded progress bars display remaining calls versus maximum daily limit (e.g. 4,999 of 5,000 or 100,000 of 100,000).
    • Reset Countdown: Shows human-readable time remaining until quota replenishment (e.g. in 23 hours), with an absolute local date/time tooltip on hover.
  6. Shared App Key Scope:
    • The footer note reminds merchants that API limits belong to the eBay App ID. Multiple seller accounts configured with identical developer keys share the same daily quota pool.
