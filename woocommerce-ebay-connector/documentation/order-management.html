Order Management & Real-Time Synchronization

The Orders tab (WC Ebay Connector → Manage Account → Orders) enables store owners to centralize fulfillment by synchronizing customer orders placed on eBay directly into WooCommerce.

1. Orders Management Table

The table provides a unified audit trail of all orders originating from eBay:

  • Ebay Order ID: Global alphanumeric eBay sales record identifier.
  • Store Order ID: Local WooCommerce order ID linking directly to the native WooCommerce Order edit page.
  • Ebay Order Status: Status reported from eBay (e.g., Completed, Active, Cancelled).
  • WC Order Status: Current WooCommerce order status badge (Pending payment, Processing, Completed, Cancelled).
  • Created At On Ebay: Timestamp recording when the order was originally placed on eBay.

2. Order Import Methods

Automated Scheduled Import

The connector registers an automated cron job with WordPress Action Scheduler (fmebay_import_order_cron). By default, it runs every 15 minutes to pull paid eBay orders without requiring manual intervention.

Manual Order Import

  1. Navigate to WC Ebay Connector → Manage Account → Orders.
  2. Click Import Orders.
  3. Choose your preferred import method:
    • By Date Range: Specify Start Time From and Start Time To to fetch historical orders placed within that specific timeframe.
    • By eBay Order ID: Enter comma-separated eBay Order IDs to fetch specific transactions on demand. This allows you to re-import missing or skipped orders without executing a full sync.

Order Sync Safeguard

To guarantee seamless order creation, catalog products should ideally be synchronized before running order imports. If an order includes items not yet present in WooCommerce, ensure that Auto Create Missing Order Products is enabled under General Settings.

3. Order Processing & Inventory Flow

  1. Order Capture: When a buyer completes checkout and payment on eBay, the order is detected during the next sync run or incoming webhook.
  2. Product Matching: The connector checks order line items against mapped WooCommerce products.
  3. Missing Product Creation: If Auto Create Missing Order Products is enabled, any item sold on eBay that does not yet exist in WooCommerce is automatically created in your catalog with proper titles, prices, and SKU records.
  4. Order Status Assignment: The imported transaction is assigned the store's Default Order Status (Processing, Completed, or On hold) configured under General Settings.
  5. Stock Deduction: WooCommerce inventory decrements immediately to reflect the units sold on eBay.
  6. Customer Notifications Suppressed: Standard WooCommerce order emails (new order, customer processing, customer completed) are automatically suppressed for imported eBay orders to avoid duplicate messages, as eBay sends buyer transactional notifications directly.
  7. Stock Synchronization: When order statuses change or inventory adjusts in WooCommerce, stock levels synchronize back across connected eBay listings in real time to prevent overselling.

4. High-Performance Order Storage (HPOS) & Native Order Source Column

WooCommerce eBay Connector is compatible with WooCommerce High-Performance Order Storage (HPOS / Custom Order Tables) and legacy post-based order storage:

  • Direct CRUD API Support: Database operations use native WooCommerce CRUD APIs (wc_get_order(), $order->save()).
  • Unified HPOS Links: Order links generated in the connector's table direct merchants automatically to the appropriate HPOS editor (admin.php?page=wc-orders or post.php).
  • Native "Order Source" Column: Across WooCommerce's main order list (WooCommerce → Orders under both HPOS and legacy table views), the connector registers an Order Source column that identifies whether each transaction originated from Ebay or WooCommerce, allowing fulfillment teams to identify marketplace sales immediately.
  • Block Checkout Compatibility: Fully compatible with modern WooCommerce checkout blocks and order attribute extensions.
