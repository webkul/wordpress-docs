Frequently Asked Questions

How does the connector prevent duplicate product listings on eBay?

The connector links exported products to their corresponding eBay Item ID so that subsequent export actions update the existing listing rather than creating a duplicate:

  • Unique Catalog SKUs: Ensure each WooCommerce product has a distinct, valid SKU.
  • Duplicate SKU Guard: In WC Ebay Connector → Manage Account → Settings → General Settings, enable the Prevent Duplicate Product setting so imported products matching existing store SKUs are not duplicated.
  • Automatic Listing Tracking: Once an item has been exported, WooCommerce stores its assigned eBay Item ID. Re-queueing that product automatically updates the live eBay listing rather than creating a new one.
Why do I see "Product category is not mapped with Ebay category"?

eBay requires every listing to be assigned to an active eBay leaf category (a bottom-level category that has no child sub-categories). If the product's assigned WooCommerce category has not yet been mapped, or was mapped to a parent category, eBay rejects the export.

Solution: Navigate to WC Ebay Connector → Manage Account → Category Mapping, click Map Category, select your WooCommerce category, drill down to the terminal eBay leaf node, and save.

What causes "Input data for tag <Item.Country> is invalid or missing"?

eBay requires an ISO country code and item postal location for all exported listings. This error appears when the country code has not been selected in account settings.

Solution: Navigate to WC Ebay Connector → Manage Account → Settings → Shipping Settings. Under the Listing Options section, select your country in the Default Country Code Type dropdown. Also verify that Pin code of item location is configured under Settings → General Settings.

Can I connect multiple eBay seller accounts?

Yes. WooCommerce eBay Connector includes a multi-account hub. You can link multiple eBay accounts across different international marketplaces (such as US, UK, Australia, Germany) and manage their individual settings, category mappings, and order queues independently from a single WordPress dashboard.

Does the connector require the PHP SOAP extension?

No. In version 5.0.0, the connector includes a native HTTP transport fallback. While servers with php-soap continue to use it seamlessly, cloud environments and shared hosts without SoapClient run all eBay Trading API calls via standard cURL HTTP transport.

Will imported eBay orders trigger customer emails from WooCommerce?

No. The connector automatically suppresses standard WooCommerce buyer transactional emails (such as New Order, Processing Order, and Completed Order) for orders imported from eBay. This prevents buyers from receiving confusing duplicate notifications, as eBay communicates transactional updates directly.

Is the connector compatible with WooCommerce High-Performance Order Storage (HPOS)?

Yes. WooCommerce eBay Connector is compatible with WooCommerce High-Performance Order Storage (HPOS / Custom Order Tables) as well as legacy post-based storage. It registers a native Order Source column across the main Orders list (WooCommerce → Orders) with clear badges indicating whether each order originated from Ebay or WooCommerce.

Can I set custom prices for eBay without altering my WooCommerce prices?

Yes. You have two flexible methods:

  • Automated Price Rules: Define percentage or fixed markups (e.g., +12% to cover eBay final value fees) under WC Ebay Connector → Settings → Price Rules.
  • Per-Product Price Overrides: Enter a specific marketplace price for any item in the Edit eBay Listing workspace prior to export.
What happens when my eBay Auth Token expires?

When an eBay user token reaches its expiration date, API requests will return an authorization error. Navigate to WC Ebay Connector → Account List, click Edit on the account, generate a fresh token from your eBay Developer Account, paste it into the credentials field, and click Verify Credentials.

Where can I find connector error logs and Action Scheduler tasks?

The connector logs events and background tasks across two native tools:

  • Scheduled Queues: Go to Tools → Scheduled Actions (or WooCommerce → Status → Scheduled Actions) and filter by group fmebay.
  • System Logs: Go to WooCommerce → Status → Logs and select the latest fmebay-* log file from the dropdown to review API payloads, HTTP status codes, and trace details.

80-Character Title LimiteBay strictly caps listing titles at 80 characters.Open the Edit eBay Listing workspace before export and craft a concise, keyword-rich 80-character marketplace title without altering your WooCommerce product title.
