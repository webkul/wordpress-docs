Features

Everything WooCommerce AliExpress Dropship 3.0.0 and the WooCommerce AliExpress Importer extension 2.0.1 can do, grouped by area. Items marked New in 3.0.0 were added in this release.

Setup and connection

  • Guided setup wizard (New in 3.0.0) — five steps: Welcome, App Credentials, Connection, Import Settings, Ready. Re-run it any time from the Help tab. Setup Wizard →
  • Secure AliExpress authorization — connect with your AliExpress app's Client ID and Client Secret; the access token refreshes automatically in the background.
  • Connection status — a Connected / Not connected indicator on the Account Setting screen and in the wizard.
  • Redesigned admin interface (New in 3.0.0) — a sidebar layout with breadcrumbs and one-click actions for every area.

Importing products

  • Import by link or product ID (New in 3.0.0) — paste up to 50 AliExpress links or IDs, one per line, and watch each result live. Import Products →
  • Import from a CSV file (New in 3.0.0) — up to 500 products per file, with optional name, price, and SEO columns; a sample CSV is provided.
  • Skip products already in the import list, or re-import to refresh their data.
  • Chrome extension import — an import button on every AliExpress product page and product card. Edit the name, price, meta title, meta description, and meta keywords before importing. Chrome Extension →
  • Bulk import from the AliExpress storefront (New in 3.0.0) — tick products on any AliExpress listing or search page, or Select all on this page, and import up to 50 at once with a live progress card. Bulk Import →
  • Redesigned extension interface (New in 3.0.0) — new connection dialogs, notifications, and status cards on AliExpress.

Creating and syncing products

  • Create Product — turn imported items into WooCommerce products in bulk, with a progress overlay. Imported Products List →
  • Simple and variable products — products with more than one AliExpress option become variable products with their own prices, stock, and images.
  • Full product data — title, images (downloaded into your Media Library), variations, attributes, SKU, stock, weight and dimensions, description, and specifications.
  • SEO meta — meta title, description, and keywords are saved and copied into Yoast SEO, Rank Math, or SEOPress when those fields are empty.
  • Bulk update from AliExpress (New in 3.0.0) — refresh price, stock, images, and details for many products at once.
  • Auto sync — refresh warehouse-assigned products automatically every chosen number of hours.
  • Import defaults — category, AliExpress categories, status, catalog visibility, stock, warehouse, language, currency, and description options. Product Setting →
  • Selling-price configuration — same as AliExpress, custom price, or increase/decrease by a percentage.

Reviews

  • Import AliExpress reviews with the product, filtered by star rating, skipping empty reviews, and optionally held as drafts for moderation. Reviews Settings →
  • Sync Reviews button to add fetched reviews to the WooCommerce product.

Warehouses

  • Warehouse managers — a dedicated WordPress role with its own restricted dashboard. Warehouse Managers →
  • Warehouses with code, title, description, origin address, and status. Warehouses →
  • Mass assign and unassign products to warehouses. Assigning Products →
  • AliExpress product list filtered by warehouse. AliExpress Products →

Orders and fulfilment

  • Orders by warehouse with placement status (Placed, N of M placed, Not placed). Orders →
  • Direct order placement via the AliExpress Open API (New in 3.0.0) — no browser redirect; review the shipping address and items, then Confirm & Place Order. Placing Orders via the API →
  • Carrier selection (New in 3.0.0) — choose Cainiao, EMS, DHL Express, FedEx, or UPS for each order, with a default carrier code in settings.
  • Background tracking sync (New in 3.0.0) — a setting that checks AliExpress order status on an hourly schedule and records tracking details as order notes.
  • Chrome extension ordering — the extension opens each ordered product on AliExpress, selects the ordered option and quantity, adds it to your cart, and shows the delivery address. Placing Orders with the Extension →
  • Order Logs with a payload inspector for every AliExpress API call. Order Logs →

Income and payouts

  • Pricing Rules — your commission on warehouse sales, fixed or percentage, by cart-total range. Pricing Rules →
  • Warehouse income — admin income, warehouse income, tax, payable and paid amounts per warehouse.
  • Pay screen and Payment Logs to record payouts. Income & Payouts →

Compatibility

  • WordPress 6.7+ (tested to 7.0), WooCommerce 10.0+ (tested to 10.9), PHP 7.4+ (tested to 8.4).
  • Declares compatibility with WooCommerce High-Performance Order Storage and Cart/Checkout Blocks.
