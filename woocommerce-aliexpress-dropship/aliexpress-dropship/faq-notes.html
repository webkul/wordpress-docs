FAQ & Notes

Do I need the Chrome extension?

Only to import products while browsing AliExpress, or to use Chrome Extension Redirect order placement. Admin and CSV imports and API order placement work without it.

Are imported products live in my store straight away?

No. Imports go to the Imported Products List first. Run Create Product there to create the WooCommerce products. See Imported Products List.

Which product types are created?

Simple products, and variable products for AliExpress items with more than one option.

Do imported products behave like normal WooCommerce products?

Yes. You can edit, categorize, and sell them like any other product. Keep in mind that Update From AliExpress and auto sync overwrite name, description, categories, price, stock, and images.

How do I add my margin to AliExpress prices?

Use Default Product Price configuration → Increase Price with a percentage in Product Setting, or set a price per product in the extension's edit dialog or a CSV file. Pricing Rules set your commission on warehouse sales, not selling prices.

Is the order paid automatically?

No. Whether you place orders with the API or the extension, you pay for them on AliExpress. API orders are created unpaid and expire if not paid in time.

Does canceling an order in the plugin cancel it on AliExpress?

No. Cancel Order only resets the placement in your store. Unpaid AliExpress orders expire on their own, or you can cancel them in your AliExpress "To Pay" list.

Do customers see tracking numbers?

The plugin records tracking details as private order notes and does not show them to customers or change the order status. Update the order and send tracking to your customer as you normally do.

Does the plugin send emails to customers?

No. The only email the plugin sends is the welcome email to a new warehouse manager.

Can one product belong to several warehouses?

No — a product belongs to one warehouse at a time, and each warehouse has one manager.

Who can use the plugin screens?

Administrators see everything. Warehouse managers see a limited view of their own warehouse — see Warehouse Manager Panel.

Does it work with HPOS and block checkout?

The plugin declares compatibility with WooCommerce High-Performance Order Storage and the Cart and Checkout blocks.

Which AliExpress sites does the extension support?

aliexpress.com, aliexpress.us, and aliexpress.ru.

Notes

  • The Chrome extension's toolbar popup still shows options for ePacket identification; in version 3.0.0 these options do not change which products are shown.
  • In the extension's edit dialog, the review options other than None follow your Reviews Settings.
  • The Latitude value on the warehouse form is not saved separately from Longitude in version 3.0.0.
