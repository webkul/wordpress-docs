Features

This page is the complete catalogue of what Smart Barcode Scan and Ordering adds to your WooCommerce store, grouped the way you will use it. Every entry links to the page that explains it step by step.

If you are evaluating the extension, read this page top to bottom. If you already have it installed, use the table below to jump to the workflow you need.

Barcode scanning

A single console for every lookup

The console lives at Webkul WC Addons → Smart Barcode Scan and opens on the Scan Console tab. The cursor is placed in the scan box automatically, so a hardware scanner works the moment the page loads — most scanners type the code and press Enter, which submits the lookup.

  • Works with any hardware barcode scanner that behaves like a keyboard, and with codes typed by hand.
  • A Recent Scans panel lists the five latest lookups with the resolved name, the scanned value, a Product / Order / Coupon badge and how long ago it happened.
  • On a match, a popup workspace opens over the console with the record already loaded.
  • On a failure, the console shows "Product or Order not found for the scanned barcode." and re-selects the code so the next scan overwrites it.

Scan from anywhere in wp-admin

A Barcode Scanner item is added to the WordPress toolbar on every admin screen. It opens a small scan card in the middle of whatever page you are on, and a match opens the same popup workspace — so a stock correction never costs you your place in another task. The quick scanner shares its cart with the console.

Keep scanning without closing the popup

The popup workspace has three tabs — Inventory, Orders and Create Order, the last one badged with the number of items in the cart — and it stays open while you keep scanning. Anything a scanner types while the popup is open, as long as the cursor is not in a text field, is looked up straight away: another product replaces the one on screen, an order switches the popup to the Orders tab, and re-scanning the order already open advances it a stage.

Two more touches keep an operator's hands on the scanner: a speaker button mutes the scan tone for the current session, and Enter triggers the primary action of whichever tab is active — Save Product, Save Order or CREATE.

What a barcode is matched against

One scanned value is checked against several fields in a fixed order, and the first match wins:

OrderMatched againstCondition
1Product IDOnly when Product ID is enabled and the scanned value is numeric
2Product SKUExact match, only when Product SKU is enabled
3GTIN, UPC, EAN or ISBNOnly when Global Unique Identifier is enabled
4Your own custom meta fieldOnly when a Custom Meta Field Key is configured
5Product or variation nameAlways runs, on published products only
6Order IDOnly when the value is numeric and nothing above matched
7Order custom meta fieldUses the same custom key, for codes stored on orders

Product variations are found directly — scan the variation's own label and its attributes are shown in the popup, and it is added to an order as that variation rather than its parent.

Scanning feedback

  • Audio feedback — a success or error tone on every scan, so an operator working down a shelf never has to look at the screen. On by default.
  • Auto clear input — empties the scan box after each successful scan, ready for the next item.
  • Add to cart after search — drops every successfully scanned product straight into the Create Order cart, which turns the console into a till.

Products and inventory

Scanning a product opens the Inventory tab of the popup with everything about that product on one screen: image, product type, publish status, stock status, current price and stock level.

These fields are editable in place and saved without leaving the popup:

FieldNotes
SKUThe code your labels are usually printed from
Regular priceIn your store currency
Sale priceLeave blank to remove a sale
Stock quantityThe counted quantity, typed or stepped
EAN codeWooCommerce's GTIN, UPC, EAN, or ISBN field
Product imageChosen from the WordPress media library

Warning

Saving from the Inventory tab always switches Manage stock on for that product and writes the quantity you entered. If a product is deliberately sold without stock tracking, do not save it from the popup — see Inventory Management.

Orders

Scanning an order — or typing its ID — opens the Orders tab with the order laid out in collapsible sections: customer, line items, the full totals breakdown, billing and shipping addresses and the customer note.

Editable from the popup:

  • Order status, including the three fulfilment statuses this extension adds. A status change writes the order note "Status updated via Smart Barcode Scan."
  • Billing address and shipping address.
  • Customer note.
  • A shipping code when one is required to advance the order.

Warning

The address boxes in the popup are free text. Saving them keeps the name and the first address line and clears company, address line 2, city, state, postcode and country. Use the WooCommerce order edit screen when a structured address must be preserved.

Order QR labels

Every order in WooCommerce → Orders can carry a scannable QR label:

  • A Generate QR row action and a button in the Actions column.
  • A Generate QRs bulk action for a whole batch of orders.
  • A drawer showing the QR code together with the order number, customer, date, status and total, with Download QR and Print QR.

Both the legacy order screen and High-Performance Order Storage are supported.

Note

If Print Barcode Products and Orders for WooCommerce is also active on your store, the QR label features are hidden so the two extensions do not duplicate each other.

Fulfilment statuses

The extension registers three WooCommerce order statuses — Picked, Packed and Shipped — placed immediately after Processing. They appear in the order list filters, the order edit screen, the bulk actions menu and WooCommerce reports, exactly like the built-in statuses.

Scanning an order that is already open in the Orders tab advances it one stage:

Pending / On hold → Processing → Picked → Packed → Shipped → Completed

  • Packed → Shipped asks for a shipping code first, and the change is refused if it is left empty — so nothing can ship without a tracking reference.
  • Shipped → Completed asks for confirmation before it goes through. The same confirmation is added to the WooCommerce order edit screen and to the order list's Complete action.
  • Orders in any other status are left untouched, and a Completed order stays Completed.

Counter ordering

+ Create Order turns scanned items into a real WooCommerce order.

CapabilityWhat it does
Scan-to-cartEach scan adds a line; scanning the same item again increases its quantity
Stock-aware quantitiesQuantity is capped at the available stock when stock is managed, and out-of-stock items are refused
Shared cartThe cart is the same one the toolbar quick scanner fills, and it survives navigating between admin pages
Customer searchFind an existing customer by username, name or email address; billing and shipping are filled from their WooCommerce profile
New user registrationCreate a WordPress user without leaving the screen, with an optional welcome email and any site role
Billing & shippingFull address, email and phone, with Same as billing address to mirror and lock the shipping block
Calculate shippingBuilds a package from the cart and the destination and returns your live shipping rates with cost and tax
CouponsValidated against existence, expiry, usage limit and product/category rules before it is accepted
Order statusAny WooCommerce status, including Picked, Packed and Shipped; Processing by default
Customer noteWritten onto the created order

Creating the order runs the normal WooCommerce pipeline — totals are calculated, coupons applied, stock reduced — and the finished order opens in a new tab.

Note

No payment gateway is called. The order is created in whichever status you choose, and you take payment however you normally do at the counter.

Auditing and logs

Everything done through the console is recorded in the Activity Logs tab: scans, product edits, order edits, order creation and settings changes.

  • Each entry stores the date and time, the scanned barcode, success or failure, the resolved product or order, the action type and the user who performed it.
  • Search across barcode, product, status and source; sort by date or barcode.
  • Click any row to expand the full detail panel.
  • Delete a single row, delete a selection in bulk, or Clear All Logs.
  • A Logs per page screen option controls pagination, and a Log History Limit setting caps how many entries are kept.

QuickScan mobile app

Alongside the admin console, the extension powers QuickScan, a phone app with its own product, order, history and settings screens. It is published on Google Play; an iOS version is coming soon.

It is not a mobile version of the console, and its /scanner/ routes do not open in an ordinary browser — a normal browser visiting /scanner/ is redirected to My Account. See QuickScan Mobile App for how to install it, who can sign in, and what each screen offers.

Limits worth knowing before you buy

  • The console reads whatever a hardware scanner or your keyboard types into the scan box; it does not open a device camera in the browser.
  • Variable parent products cannot be added to an order — scan the specific variation instead.
  • Orders created from the console do not charge a payment gateway.
  • The Activity Logs tab covers console activity only; scans made in the QuickScan app are stored separately.
