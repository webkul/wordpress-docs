One console for scanning, stock corrections and counter sales

Smart Barcode Scan and Ordering adds a single admin screen where a barcode is all your staff need to find a product, find an order, or ring up a sale.

Scanner Console
A focused scan box that takes hardware scanner input or a typed code, answers in a popup, and keeps the last five lookups in a Recent Scans panel.
Product and Order Lookup
One code is matched against product ID, SKU, GTIN, UPC, EAN, ISBN, a custom meta field, the product name and the order ID, so any label your store prints resolves.
Inventory Quick Edit
Correct the stock quantity, SKU, regular price, sale price, EAN code and product image straight from the scan popup, without opening the product editor.
Counter Order Creation
Scan items into a cart, attach or register a customer, fill billing and shipping, calculate shipping, apply a coupon, and create a real WooCommerce order.
Fulfilment Order Statuses
Three extra WooCommerce statuses — Picked, Packed and Shipped — advanced one stage per scan, with a tracking code required before an order can ship.
Order QR Labels
Generate, download or print a QR label for any order from the WooCommerce order list, one order at a time or for a whole selection in bulk.
Customer Attach and Register
Search existing users by name, username or email, or register a brand new customer, without ever leaving the order you are building.
Activity Log Audit Trail
Every scan, product edit, order edit, order creation and settings change is recorded with a timestamp and the user who did it, then searched and sorted.
Scanner Settings
Choose which fields a barcode is matched against, turn the scan beep on or off, clear the input automatically, and cap how much log history is kept.
Proof of Delivery, End to End
A shipping code before an order can leave as Shipped, a six-digit code the customer reads off their own order page to close the delivery, a live Order Placed to Delivered timeline they can follow, and a Delivery Agent account for couriers that can see nothing else.
