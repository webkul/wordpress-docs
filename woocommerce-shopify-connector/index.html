What's New in v5.0.0

Item-Wise Shopify Listing Editor — Customize titles, pricing rules, stock safety buffers, tags, vendor, barcodes, weights, HS tariff codes, and field sync toggles per product and account. Listing Editor Guide →
WooCommerce Products Bulk Queue — Directly export or update to Shopify from the WooCommerce Products table with an interactive real-time modal progress queue. Bulk Export Guide →
Webhook Health Diagnostics & Auto-Repair — Monitor all 8 webhook subscriptions (including INVENTORY_LEVELS_UPDATE and CUSTOMERS_UPDATE) and auto-repair missing webhooks with 1 click. Webhook Diagnostics Guide →
Barcode / GTIN Synchronization — Map barcodes to WooCommerce Core GTIN (_global_unique_id) or custom meta keys with duplicate conflict prevention. Barcode Guide →
Multi-Store Auto Product Export — Automatically export newly published WooCommerce products to multiple connected Shopify accounts. Auto Export Guide →
Map Order Status — Bidirectionally map Shopify order lifecycle, fulfillment, and financial states to WooCommerce order statuses with 1-click reset to defaults. Status Mapping Guide →
Map Product Status — Bidirectionally map Shopify product lifecycle statuses (Active, Draft, Archived) to WooCommerce product statuses with auto-sync indicators and 1-click reset. Product Status Guide →
WooCommerce Orders Integration — HPOS-ready Shopify Sync column and single order Sync Details metabox with live status and 1-click sync. Order Integration Guide →
Filtered Imports & Catalog Protection — Filter imports by date range or specific order IDs, with per-item Include/Exclude protection. Filtered Imports Guide →
