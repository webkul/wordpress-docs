Exporting Orders

Order export creates WooCommerce orders on Shopify — useful when Shopify is your fulfillment hub. Orders can be exported per row, in bulk, or automatically at checkout, and Shopify fulfillment tracking flows back to the WooCommerce order.

Open the store workspace and go to Orders → Export Order.

Before you start

In General Configuration, decide whether exported orders include or exclude shipping cost, tax, and discounts (Order Settings section). Exported products must already exist on Shopify — export the products first.

Manual export

The table lists WooCommerce orders with Store Order ID, Customer Name, Customer Email, Order Status, Shopify Order Id, Export Status.

  • Single order — select the Export button in the row.
  • Several orders — tick them, choose Bulk actions → Export, and select Apply.
  • Export Orders (Bulk toolbar) — click Export Orders in the toolbar to submit all unexported WooCommerce orders to the queue in a single batch.
  • Update Orders (Bulk toolbar) — click Update Orders in the toolbar to re-push latest customer notes, addresses, and fulfillment details for all previously mapped orders.

When a batch export or update runs, an interactive background job panel displays live progress, completed item counts, and status indicators without blocking page navigation.

Orders already sent are skipped with "Order(s) Already Exported". When Shopify accepts the order, it is created with inventory deducted according to each product's stock policy, and the row's Export Status updates.

Automatic export at checkout

Set Auto Export Order in General Configuration to All or to specific statuses (Pending, Processing, On hold, Completed). When a customer completes checkout on WooCommerce and the new order's status matches, the order is exported to Shopify immediately — no manual action.

WooCommerce Orders List Integration

The connector integrates directly into WooCommerce core order management screens (compatible with both HPOS and legacy post-based order tables).

Navigate to WooCommerce → Orders (admin.php?page=wc-orders):

  • A dedicated Shopify Sync column displays real-time sync indicators:
    • 🟢 Synced with Shopify — Displays the Shopify order ID (e.g. #18968396759254) and links directly to the connected store.
    • ⚪ Unsynced — Indicates orders awaiting sync or excluded from export.

Single Order Edit — Shopify Sync Details Metabox

Open any WooCommerce order in the order editor to inspect its Shopify connection state:

The Shopify Sync Details panel displays:

  • Sync Status: Real-time badge indicating whether the order is currently synchronized.
  • Shopify Order Number: Exact Shopify order number with deep link to open the order in the Shopify Admin.
  • Connected Shopify Store: Displays store name and domain.
  • Sync Source: Identifies whether the order was Imported from Shopify or Exported to Shopify.
  • Sync Order with Shopify Button: Allows store operators to manually trigger an immediate AJAX sync refresh for this specific order.

Map Order Status

To configure how Shopify fulfillment states and financial transaction statuses translate to WooCommerce order statuses (and vice-versa), use the dedicated status mapper: → Full guide: Map Order Status.

Map Old Orders

If you connected the plugin to a store that already had matching orders on both platforms, use Orders → Map Old Orders to link them instead of exporting duplicates.

The table shows each WooCommerce order with a Mapping Status (green tick = linked, red cross = not linked). Select Map on a row — or tick rows and use Bulk actions → Map — and the connector finds the matching Shopify order and records the link. Mapped orders are treated as already exported.

Real-Time Order Fulfillment Sync

The connector provides bi-directional fulfillment tracking synchronization between WooCommerce and Shopify:

  • WooCommerce to Shopify — When you fulfill an imported Shopify order in WooCommerce (marking the order Completed and adding tracking numbers/carrier details), the connector triggers Shopify's fulfillment API in real time. The order on Shopify is marked fulfilled, and shipment tracking information is recorded directly on Shopify without manual entry.
  • Shopify to WooCommerce — When an order is fulfilled on Shopify with tracking details, the connector writes Tracking Company, Tracking Number, and Tracking URL onto the matching WooCommerce order line items. Customers see these in their WooCommerce account order details and in order confirmation emails.

Bi-Directional Order Updates

With the ORDERS_UPDATED webhook active and Order Updates from Shopify enabled, modifications to orders on Shopify (financial status updates, fulfillment events, address adjustments) are synced back to WooCommerce automatically.
