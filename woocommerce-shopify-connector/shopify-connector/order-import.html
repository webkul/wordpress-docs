Importing Orders

Order import brings Shopify orders into WooCommerce so fulfillment, reporting, and customer history live in one place. Like products, it is a two-phase flow: Import Order stages the data, Create Imported Orders builds the WooCommerce orders.

Open the store workspace and go to Orders → Import Order.

Before you start

In General Configuration, set:

  • Import Orders As — the WooCommerce status given to imported orders.
  • Import Orders Re-Send Email — leave on Disable (default) so customers are not emailed again by WooCommerce for orders they already placed on Shopify.

Filtered Order Import Options

The connector provides three order import modes via the mode selector dropdown:

  • Import All — Pulls all eligible orders from Shopify. Select Import Order to stage the records.
  • Import Date-wise — Restricts the import window to orders placed within specific dates. Set From Date and To Date using the native datepicker, then select Import Order.
  • Import By ID — Imports specific orders by entering their Shopify Order IDs (single ID or comma-separated list, e.g. 6234567890123, 6234567890124).

Once staged, orders are listed with Store Order Id, Order Status, Order Created Date, Shopify Order Id, Shopify Order Number.

Creating WooCommerce Orders

Select Create Imported Orders (or the button indicating staged count, e.g. "Create Imported Orders (16)") to build native WooCommerce orders. If nothing is staged the button reads "Orders are not available for create".

During creation, the connector:

  • Applies your chosen order status.
  • Attaches the ordered products (import products first — orders whose products are missing are reported: "not Created due to product unavailability so please import products.").
  • Creates any missing tax rates automatically so financial totals match.
  • Stores Shopify metadata (shopify_order, shopify_store_id), preventing duplicate re-export back to Shopify.

Orders without a customer email are skipped with "not Created due to email not available."

Automatic order import

With webhooks generated and Auto Import Order set to Enable, new Shopify orders arrive in WooCommerce automatically within moments of being placed — no manual import needed.

Managing imported orders

  • Edit on a row opens the order in WooCommerce's order editor.
  • Bulk actions → Delete removes staged/imported records from the connector's list (the WooCommerce order itself is managed from WooCommerce → Orders).
  • Search by ID filters the table.
