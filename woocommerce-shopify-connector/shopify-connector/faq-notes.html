FAQ & Notes

Can I connect more than one Shopify store?

Yes. Add as many accounts as you need from Add Account; each store gets its own workspace, settings, webhooks, price rules, and analytics. A store-switcher dropdown moves you between them.

Which product types are supported?

Simple and variable products, in both directions. Other WooCommerce product types (grouped, external) and Shopify product types outside the standard options/variants model are not synced.

Do imported Shopify products behave like normal WooCommerce products?

Yes. They are real WooCommerce products — you can edit, categorize, and sell them exactly like products you created directly. The connector additionally remembers the link to Shopify so updates can flow.

Who can use the connector's admin screens?

Administrators — the plugin pages require the manage options capability. Shop Manager accounts cannot open the connector pages.

Will my customers get duplicate order emails?

No — by default WooCommerce's new-order and processing/completed emails are suppressed for orders imported from Shopify. You can turn them back on with Import Orders Re-Send Email → Enable in General Configuration.

Does fulfilling an order on Shopify complete it in WooCommerce?

Yes, when Map Order Status is configured and Order Updates from Shopify is enabled. When an order is fulfilled on Shopify, the connector looks up your fulfillment mapping (e.g. Fulfilled → Completed) and updates the WooCommerce order in the background. In addition, carrier tracking details (carrier name, tracking number, tracking URL) flow onto the WooCommerce order line items automatically so your customers can track delivery.

How does Map Order Status work?

Under Orders → Map Order Status, store owners can map Shopify order lifecycle states (Cancelled), fulfillment statuses (Fulfilled, Unfulfilled, Partially Fulfilled, On Hold, Restocked), and financial states (Paid, Pending Payment, Authorized, Partially Paid, Refunded) to your preferred WooCommerce order statuses. The screen also features a 1-click Reset to Default Mappings button to restore standard Webkul recommendations at any time.

Can I manage Shopify synchronization from core WooCommerce screens?

Yes. The connector integrates directly into native WooCommerce interfaces:

  • WooCommerce Orders List: Features a dedicated Shopify Sync column displaying sync state badges and Shopify Order numbers.
  • Single Order Edit Screen: Includes a Shopify Sync Details metabox showing the synced state, Shopify Order ID, connected store name, sync source, direct link to Shopify Admin, and an instant AJAX Sync Order with Shopify button.
  • Single Product Edit Screen: Features a Shopify Connector Settings metabox to exclude individual products from sync, specify custom Shopify title overrides, set item price rules, or configure stock safety buffers.

What happens to synced data if I delete an account?

The WooCommerce products, orders, users, and content already created stay in place. Only the connection and its sync links are removed, and real-time updates stop — the delete dialog warns you about exactly this.

Does real-time sync work on a local or staging site?

Manual imports and exports work anywhere the server can reach Shopify. Real-time sync additionally needs Shopify to reach you — the site must be publicly accessible over HTTPS for webhooks to arrive.

Can I choose which fields real-time sync updates?

Yes — the Real-Time Sync – Fields to Update lists in General Configuration control the synced fields per direction (title, description, images, price, categories, weight, barcode). See Webhooks & Real-Time Sync.

Are stock levels location-aware?

Yes. Product import and export follow the Shopify location chosen in Select Shop Location under General Configuration. The products you import and the stock you see and update in WooCommerce belong to that selected location — not the total of all your Shopify locations.

  • Choose a location first. Until one is selected, Import Product, Create Imported Products and Refresh Products stay disabled with the notice "Please select a Shopify location first. Product stock is imported from the selected location." and a Set location in General Configuration → link. Products cannot be exported without a location either.
  • Import (Shopify → WooCommerce) — each product and variant is created with the available quantity at the selected location. A variant that is not stocked at that location comes in with a stock of 0.
  • Export (WooCommerce → Shopify) — stock quantities are written to the selected location only; your other Shopify locations are left untouched.
  • Ongoing stock updates — with Product Auto-Sync set to Shopify To WooCommerce, WooCommerce To Shopify or Both Way, stock changes move between WooCommerce and the selected location in the chosen direction. Shopify changes arrive through the inventory_levels/update webhook, and changes at any other location are ignored. Stock is exchanged as changes (+/−), not overwritten, so sales made on both stores at the same time are all counted.
  • No double deduction on orders — an order imported from Shopify does not reduce WooCommerce stock a second time, and an order exported to Shopify does not reduce the selected location's stock again when WooCommerce stock is already being pushed.

Selling from more than one Shopify location?

Pick the location whose stock should mirror your WooCommerce store (usually your main warehouse) in Select Shop Location and save. Stock held at other locations stays in Shopify and is not imported, exported or updated by the connector.

How does the Item-Wise Shopify Listing Editor work?

The listing editor allows store managers to customize product titles, prices, stock safety buffers, tags, vendor, barcodes, weights, and international shipping attributes (HS tariff codes, country of origin) on a per-product and per-account basis. It also lets you lock specific attributes (e.g. description or images) so automated sync leaves them untouched. Overrides can be reverted at any time using the Reset to Defaults button.

Can I export products directly from the WooCommerce Products list?

Yes. From Products → All Products in the WordPress admin, select items and choose Export/Update to Shopify from the Bulk actions dropdown. An interactive progress modal opens with a live counter, status badges (Queued, Syncing, Exported, Updated, Failed), retry failed button, and background queue handling.

How does Barcode / GTIN mapping handle duplicates?

Under General Configuration, you can choose between WooCommerce Core GTIN / UPC (_global_unique_id) and Custom Meta Key. To prevent catalog corruption, the connector automatically skips duplicate barcodes during import/sync and logs a warning in WooCommerce status logs.

How does Webhook Health Diagnostics and 1-Click Repair work?

On the Account Settings → Webhooks tab, the connector displays a health status badge (🟢 Healthy / 🔴 Action Required). If any of the 8 required webhooks (ORDERS_CREATE, ORDERS_FULFILLED, ORDERS_UPDATED, PRODUCTS_CREATE, PRODUCTS_UPDATE, PRODUCTS_DELETE, INVENTORY_LEVELS_UPDATE, CUSTOMERS_UPDATE) are missing or have broken URLs, clicking 1-Click Repair automatically re-registers and fixes them immediately.

Is the plugin compatible with HPOS and multisite?

Yes — WooCommerce High-Performance Order Storage (HPOS), Cart/Checkout Blocks, and WordPress multisite are all supported.

Notes

  • Documented version: 5.0.0. Screens and options may differ on other versions.
  • The daily sync digest email and log data retention (1–90 days, default 60) can be customized per connected store in General Configuration → Analytics & Sync Reports.
  • All sync activity is logged under WooCommerce → Status → Logs for support purposes.
  • Every message the connector can show is listed in the Error Message Index.

Support

For anything this guide doesn't cover, contact the Webkul team through the Webkul Support Desk — include your plugin version and, for sync issues, the error code from the Analytics Dashboard.
