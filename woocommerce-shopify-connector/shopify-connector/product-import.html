Importing Products

Product import is a two-phase process: first the connector imports product data from Shopify into a staging list, then a create step turns the staged records into real WooCommerce products. This lets you pull a large catalog safely and see counts before anything is created.

Open the store workspace and go to Products → Import Product.

Before you start

  • Set the Default Category, Products to Import, image size, and product status options in General Configuration.
  • If you import by mapped categories, complete Category Mapping first.
  • For large catalogs, set Create Product In Background to Yes.

Filtered Import Options

The connector provides three import modes via the mode selector dropdown:

  • Import All — Imports all eligible Shopify products according to your Products to Import and Shopify Status configuration. Select Import From Shopify to pull the catalog.
  • Import Date-wise — Restricts the import window to products created or updated within specific dates. Select a From date and a To date using the native datepickers, then select Import From Shopify.
  • Import By ID — Pulls specific Shopify products by entering their Shopify product IDs (single ID or comma-separated). IDs that do not exist on Shopify are skipped and reported.

A progress bar and live counters track the pull. Imported records appear in the staging table with their Shopify ID, name, SKU, price, type, and status.

Phase 2 — Create WooCommerce products

Select Create Imported Products (or the button indicating staged count, e.g. "Create Imported Product (25)"). The connector builds native WooCommerce products from the staged data:

Shopify dataBecomes in WooCommerce
Title, descriptionProduct name and description (HTML kept or stripped per your setting)
Price and compare-at priceSale price and regular price
SKUProduct SKU (duplicates are renamed with a duplicate_ prefix)
Inventory quantity and policyStock quantity; continue selling when out of stock becomes back-orders allowed
Weight, tags, barcodeWeight, product tags, GTIN/EAN field (mapped to Core GTIN or Custom Meta Key)
CollectionsMapped WooCommerce categories, or your default category
ImagesFeatured image and gallery
Options and variantsAttributes and variations, each with its own SKU, price, stock, weight, and image

Simple and variable products are both supported. While creation runs, the screen shows progress — "Creating Products", a progress bar, and counters such as "25 Products created out of 100" and the number of images still pending.

Background mode

With Create Product In Background enabled, creation continues server-side and you can leave the page. The button area shows that products and images are being created in the background, and a Stop Background Process button lets you halt it. Only one store can run a background creation at a time.

Catalog Protection — Include / Exclude Controls

Every product in the imported table has an Include / Exclude toggle and badge:

  • Included (green badge) — Product participates in automated background sync, stock updates, and webhook synchronization.
  • Excluded (red badge) — Sync is paused for this specific product. Changes on Shopify will not overwrite WooCommerce product attributes.

To change protection status in bulk, tick the items and select:

  • Bulk actions → Exclude from Import / Sync
  • Bulk actions → Include in Import / Sync

The product list

Once created, products appear in the table with columns WC Product ID, Product Image, Shopify ID, Product Name, SKU, Product Price, Type, Sync Status, WC Product Status. From here you can:

  • WC Product Status — displays the live WooCommerce catalog status (Published, Draft, Pending Review, Private) mapped directly from the Shopify product status according to your Map Product Status rules.
  • Edit — open the WooCommerce product editor.
  • Edit Shopify Listing — open the Item-Wise Shopify Listing Editor to customize title, pricing buffer, safety stock, vendor, tags, or customs fields specifically for this store.
  • Update — re-pull that product's current data from Shopify.
  • Bulk actions → Update From Shopify — refresh several products at once.
  • Bulk actions → Delete — remove the sync record.

Product Status Lifecycle & Mapping

When imported Shopify products are created in WooCommerce:

  • Map Product Status Rules: The connector checks your Map Product Status configuration. If Shopify's product status (ACTIVE, DRAFT, or ARCHIVED) has a mapped WooCommerce status, the product is created with that exact status.
  • Default Fallback: If no specific mapping is selected, the connector falls back to the Default Product Status configured in General Configuration.
  • Automated Webhook Updates: When a product's status changes on Shopify, the incoming webhook automatically updates the WooCommerce product status in real time if Product Status is enabled under Fields to Update (Shopify to WooCommerce).

Refreshing the whole catalog

Refresh Products re-pulls updates for every imported product in the background — useful when real-time sync is off or products have drifted out of sync. While a refresh is queued, the button changes to Stop Refresh Products Process and a counter shows how many products are still being refreshed.

A refresh takes time

The connector itself warns that this is a time-taking process. Use Refresh Products only when real-time sync is off or products are out of sync — with webhooks active, day-to-day changes arrive automatically.

Common messages

MessageMeaning
"Products Skipped" / "Product(s) skipped due to category not mapped"Products outside your mapped categories were not imported (with Only mapped categories product).
"Product ID(s) were not found on Shopify and skipped"One of the comma-separated IDs doesn't exist on that store.
"Products not available for create"Nothing is staged — run Phase 1 first.
"Another product import is in process."A second import was started while one is running; wait for it to finish.
