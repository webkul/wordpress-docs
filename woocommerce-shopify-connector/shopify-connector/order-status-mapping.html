Map Order Status

Order status mapping allows store administrators to define precise, bidirectional relationships between Shopify order statuses and WooCommerce order statuses. Because Shopify separates an order's lifecycle, financial payment state, and fulfillment status into distinct attributes while WooCommerce uses a unified order status model, mapping ensures both platforms mirror each other accurately.

Open the store workspace (Manage Account), navigate to Orders → Map Order Status.

Why Map Order Statuses?

In multi-channel retail operations, order state discrepancies cause severe fulfillment bottlenecks and accounting errors:

  • When a customer or staff cancels an order on Shopify, the corresponding WooCommerce order should automatically transition to Cancelled.
  • When a warehouse fulfills items on Shopify, the WooCommerce order should advance to Completed.
  • When payment is captured on Shopify (e.g. for pending COD or bank transfers), the WooCommerce order should move to Processing.
  • When fulfillment tracking is added or status updated in WooCommerce, the change pushes back to Shopify.

The Map Order Status table coordinates these workflows seamlessly.

Supported Shopify Statuses

The connector organizes mappable Shopify statuses into three functional groups:

1. Order Lifecycle

Shopify StatusDescriptionRecommended WooCommerce Mapping
CancelledThe order was cancelled by the merchant or customer on Shopify.Cancelled

2. Fulfillment Statuses

Shopify StatusDescriptionRecommended WooCommerce Mapping
FulfilledAll line items have been fulfilled and shipped on Shopify.Completed
UnfulfilledOrder has been placed on Shopify, but items are awaiting shipment.Processing
Partially FulfilledSome line items have been fulfilled, while others remain unfulfilled.Processing (or custom status)
On HoldFulfillment is held or paused on Shopify.On hold
RestockedAll items in this order were restocked into inventory on Shopify.Refunded or Cancelled

3. Financial Statuses

Shopify StatusDescriptionRecommended WooCommerce Mapping
PaidPayment has been captured in full for the order.Processing
Pending PaymentPayment is pending (e.g. COD, wire transfer, manual invoice).Pending payment
AuthorizedPayment has been authorized by the customer's payment provider, but not yet captured.On hold
Partially PaidA partial payment has been captured for the order.On hold
RefundedThe payment has been refunded in full on Shopify.Refunded

Configuring Status Mappings

  1. In the Map Order Status table, locate each Shopify status row.
  2. Under the WooCommerce Order Status column, select the corresponding target status from your WooCommerce store dropdown.
  3. Review related real-time sync indicators displayed at the top of the card:
    • Order Updates from Shopify: Indicates whether incoming order status modifications arrive via webhooks in real time.
    • Imported Order Status Sync: Indicates whether fulfillment changes in WooCommerce push back to Shopify in the background.
    • Order Updates to Shopify: Indicates whether order updates on exported orders push back to Shopify. (Select Edit in General Configuration to modify these toggles).
  4. Select Save Order Status Mapping to store your changes. The confirmation notice "Order status mapping updated successfully!" confirms the save.

Reset to Default Mappings

If your store requires restoring standard Webkul recommendations:

  1. Select the red Reset to Default Mappings button below the mapping form.
  2. The connector immediately restores the recommended mapping table and displays "Order status mappings have been reset to default values successfully!".

Fallback Status

If an imported Shopify order arrives with a status combination not mapped in this table, the connector safely falls back to the Import Orders As setting configured in General Configuration.
