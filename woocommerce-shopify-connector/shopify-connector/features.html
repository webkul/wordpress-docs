Features

The complete capability list for WooCommerce Shopify Connector v5.0.0, grouped by area. Each feature links to its guide.

Store connection

  • Connect multiple Shopify stores and manage them from one screen.
  • Two connection methods: Shopify Developer Dashboard app (Client ID + Client Secret, OAuth authorization) and legacy custom app (Admin API access token). → Connecting a Shopify Account
  • Guided Setup Wizard for the first connection, with credential verification. → Setup Wizard
  • Account list with list/grid views, search, bulk delete, and per-store Manage Account workspace. → Managing Accounts

Products & Catalog Management

  • Item-Wise Shopify Listing Editor: Dedicated listing customizer to override title, custom pricing adjustments, stock safety buffer, vendor, tags, barcodes, weights, HS tariff codes, country of origin, delivery profiles, and field-level sync toggles on a per-product and per-account basis. → Exporting Products
  • Map Product Status: Bidirectionally map Shopify product lifecycle statuses (Active, Draft, Archived) to WooCommerce product statuses (Published, Draft, Pending Review, Private), complete with real-time sync dependency indicators, master setting shortcuts, and 1-click reset to defaults. → Map Product Status
  • WC Product Status in Import Table: Live column in the imported products table displaying each item's local WooCommerce catalog status at a glance. → Importing Products
  • Product Edit Screen Metabox: Quick item-level override controls directly inside the native WooCommerce product editor (post.php?post=...&action=edit) to exclude products, override titles, adjust prices, and set stock safety buffers. → Exporting Products
  • WooCommerce Products List Bulk Queue: Directly export or update products to Shopify from the native WooCommerce Products table (edit.php?post_type=product) with an interactive real-time modal progress queue, retry failed, and stop process actions. → Exporting Products
  • Import simple and variable Shopify products with base image, gallery images, name, price, compare-at price, SKU, description, quantity, weight, tags, barcode (GTIN), and variant attributes with options. → Importing Products
  • Filtered imports: Import all products, import date-wise with From/To date filters, or import specific products by comma-separated Shopify product IDs.
  • Catalog protection: Item-level Include / Exclude toggles and bulk actions (Exclude from Import / Sync, Include in Import / Sync) to protect specific products from automated sync and overwrites.
  • Filter imports by Shopify product status (Active / Archived / Draft / All).
  • Choose the WooCommerce product status for imported products, and the imported image size.
  • Create Product In Background mode for large catalogs, with progress indicators and a stop control.
  • Refresh Products button re-pulls product updates from Shopify in the background.
  • Export All Products and Refresh Products bulk actions directly in the Product Export toolbar.
  • Auto-export rule: Automatically export newly published WooCommerce products to one or multiple selected Shopify stores simultaneously.
  • Multi-Category mapping: Modern multi-row mapper to link multiple WooCommerce categories to Shopify collections with dynamic row additions. → Category Mapping
  • Barcode / GTIN synchronization: Sync variant barcodes with WooCommerce Core GTIN (_global_unique_id) or custom postmeta keys with automatic duplicate uniqueness protection. → General Configuration
  • Price rules: Fixed or percentage increase/decrease per price band, per store, applied on import or export. → Price Rules

Orders & Fulfillment

  • Map Order Status: Dedicated status mapping workspace to map Shopify order lifecycle (Cancelled), fulfillment (Fulfilled, Unfulfilled, Partially Fulfilled, On Hold, Restocked), and financial states (Paid, Pending Payment, Authorized, Partially Paid, Refunded) to WooCommerce order statuses, with Reset to Defaults and Save actions. → Map Order Status
  • WooCommerce Orders Screen Integration: HPOS and legacy table integration adding a Shopify Sync column showing synced status badges and Shopify Order IDs. → Exporting Orders
  • Single Order Edit Metabox: "Shopify Sync Details" panel on WooCommerce single order screens showing Shopify order number, connected store, sync origin, deep link to Shopify Admin, and an instant AJAX sync button. → Exporting Orders
  • Export Orders & Update Orders Toolbar: Bulk toolbar buttons to export unexported orders and update mapped orders in the background. → Exporting Orders
  • Import Shopify orders with three distinct scopes: Import All, Import Date-wise, or Import By ID (single or comma-separated Shopify order IDs). → Importing Orders
  • Export WooCommerce orders to Shopify per order or in bulk; control whether shipping, tax, and discounts are included. → Exporting Orders
  • Real-Time Order Fulfillment Sync: Fulfilling an imported Shopify order in WooCommerce automatically updates fulfillment status and pushes carrier tracking numbers and URLs back to Shopify.
  • Real-Time Order Updates: Subscribed to ORDERS_UPDATED webhook to sync ongoing modifications from Shopify.
  • Automatic order export at checkout for the order statuses you select.
  • Automatic order import via webhook when new orders are placed on Shopify.
  • Map Old Orders links pre-existing WooCommerce orders to their Shopify counterparts so they are not exported twice.
  • Shopify tracking number, carrier, and URL written to WooCommerce orders when fulfilled on Shopify.
  • Optionally re-send WooCommerce order emails for imported orders (off by default).

Other store data

  • Import, create, and Update Customers from Shopify as WooCommerce customer accounts. → Importing Store Data
  • Real-Time Customer Updates: Synchronize customer contact and shipping address modifications from Shopify to WooCommerce in real time via shopify_acct_customer_update_import_sync. → Importing Store Data
  • Import and update Shopify pages, coupons (discount codes), and blog posts.
  • Import Shopify tax rates into WooCommerce standard rates. → Shipping & Tax
  • Import Shopify shipping zones and rates as WooCommerce zones with flat-rate methods.

Real-time sync & Diagnostics

  • Webhook Health Diagnostics & 1-Click Auto-Repair: Proactively checks webhook subscription health, displays status badges (🟢 Healthy / 🔴 Action Required), and auto-repairs missing subscriptions with a single click. → Webhooks & Real-Time Sync
  • Registers 8 webhook subscriptions: ORDERS_CREATE, ORDERS_FULFILLED, ORDERS_UPDATED, PRODUCTS_CREATE, PRODUCTS_UPDATE, PRODUCTS_DELETE, INVENTORY_LEVELS_UPDATE (real-time stock synchronization), and CUSTOMERS_UPDATE (real-time customer profile & address sync).
  • Real-Time Inventory Level Synchronization (INVENTORY_LEVELS_UPDATE): Instantaneous stock balance alignment across Shopify locations and WooCommerce products, processed safely with delta calculations via asynchronous ActionScheduler queues. → Webhooks & Real-Time Sync
  • Product Auto-Sync direction: disabled, Shopify → WooCommerce, WooCommerce → Shopify, or both ways.
  • Fields to Update: Choose exactly which product fields sync in each direction (title, description, images, price, categories, weight, barcode).
  • Webhook events are queued and processed asynchronously in the background, with automatic recovery of stalled queues.

Performance & Background Architecture

  • Dedicated background queues (class-wkwooshopify-list-action-process.php) for heavy batch exports, imports, updates, and deletions.
  • Memory/RAM optimization and query chunking to comfortably handle large multi-thousand SKU catalogs without server timeouts.
  • Real-time job cards showing live item-by-item progress details during execution.

Monitoring & reporting

  • Sync Performance Dashboard per store: products/orders synced, failures, success rates, daily trend charts, embedded Webhook Health Diagnostic card, and a Top Sync Errors table with suggested fixes. → Analytics Dashboard
  • Time period filter: last 24 hours, last 7 days, or last 30 days.
  • CSV export of sync events.
  • Configurable daily email digest: Enable/disable daily reports, specify custom recipient emails, and configure delimiters in General Configuration. → General Configuration
  • Customizable Log Retention: Set data retention from 1 to 90 days (default 60 days) per connected account.
  • All operations are also written to the WooCommerce logs for deep troubleshooting.

Compatibility

  • WooCommerce High-Performance Order Storage (HPOS) and Cart/Checkout Blocks compatible.
  • Tested and verified on WordPress 7.1 and WooCommerce 11.0, PHP 7.4 to 8.4.
  • WordPress multisite compatible.
  • Works with Shopify REST Admin API 2025-10 and GraphQL Admin API 2024-01.
