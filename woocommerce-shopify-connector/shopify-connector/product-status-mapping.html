Map Product Status

Product status mapping provides precise, bidirectional lifecycle synchronization between Shopify product statuses and WooCommerce product statuses. Shopify organizes a product's visibility into distinct lifecycle states (ACTIVE, DRAFT, ARCHIVED), while WooCommerce uses core post statuses (Published, Draft, Pending Review, Private). Mapping these statuses ensures that catalog visibility, drafts, and discontinued items mirror each other across both storefronts without manual intervention.

Open the store workspace (Manage Account), then navigate to Products → Map Product Status.

Why Map Product Statuses?

In multi-channel retail operations, inconsistent product statuses cause severe inventory and marketing discrepancies:

  • Prevent Premature Sales: When a product is set to Draft on Shopify while awaiting photography or supplier confirmation, it should import as Draft (or Pending Review) in WooCommerce rather than going live immediately.
  • Automate Catalog Launches: When a draft product is published on Shopify (becoming Active), the corresponding WooCommerce product automatically switches to Published via webhooks.
  • Discontinue & Archive Gracefully: When seasonal or discontinued merchandise is Archived on Shopify, WooCommerce automatically updates the item to Private or Draft, hiding it from customer searches while preserving purchase history and analytics.
  • Bi-Directional Status Updates: Modifying a product status in WooCommerce (e.g., publishing a draft item) immediately pushes the corresponding status to Shopify when bidirectional synchronization is active.

Supported Shopify Product Statuses

The connector provides mapping controls for all standard Shopify product lifecycle statuses:

Custom Post Statuses Supported

If your WooCommerce store utilizes custom registered post statuses (e.g., custom marketplace workflow statuses), the mapping dropdown automatically discovers and displays them, strictly excluding order statuses.

Synchronization Settings Dependency Banner

At the top of the Map Product Status screen, an interactive dependency banner displays the real-time operational status of related master toggles configured in General Configuration:

  1. Product Auto-Sync Direction:
    • Both Ways — Full real-time synchronization between WooCommerce and Shopify.
    • Shopify to WooCommerce — Only updates from Shopify modify WooCommerce products.
    • WooCommerce to Shopify — Only updates from WooCommerce push to Shopify.
    • Disabled — Automated status synchronization is paused.
  2. Woo → Shopify Status Sync:
    • Indicates whether changing a product status in WooCommerce automatically pushes to Shopify. Controlled via Fields to Update (WooCommerce to Shopify) → Product Status.
  3. Shopify → Woo Status Sync:
    • Indicates whether incoming Shopify status changes (via PRODUCTS_UPDATE webhooks or manual refresh) update WooCommerce products. Controlled via Fields to Update (Shopify to WooCommerce) → Product Status.

Select Configure Settings → on the right side of the banner to open General Configuration directly and modify these settings.

Configuring Product Status Mappings

To establish or modify status relationships:

  1. In the Map Product Status table, review each Shopify status row.
  2. Under the WooCommerce Product Status column, select the desired target status from the dropdown:
    • Select -- Default / Do Not Change -- if you want the connector to preserve the product's existing status during updates.
    • Or select an explicit target: Published, Draft, Pending Review, or Private.
  3. Select Save Status Mapping in the action footer.
  4. A green admin notice "Product status mapping updated successfully!" confirms your configuration is active.

1. Product Import & Creation

When importing products from Shopify via Importing Products:

  • If Map Product Status is configured, each imported product receives the mapped WooCommerce status corresponding to its Shopify state.
  • If no specific mapping is selected for a status, the connector falls back to the Default Product Status configured in General Configuration.

2. Real-Time Webhook Updates

When a product's status changes on Shopify, the PRODUCTS_UPDATE webhook triggers:

  • If Product Status is checked under Fields to Update (Shopify to WooCommerce) and auto-sync is enabled, WooCommerce immediately transitions the local product to the mapped status.

3. Product Export & WooCommerce Edits

When creating or updating products from WooCommerce:

  • During manual or bulk export from Exporting Products, WooCommerce statuses are converted to the matching Shopify status before payload delivery.
  • When an administrator modifies a connected product in the standard WooCommerce editor (e.g. changing status from Draft to Published), the status updates on Shopify in real time if Product Status is enabled under Fields to Update (WooCommerce to Shopify).

Viewing Status in the Import Table

To make status tracking effortless without opening individual product editors, the Import Product table includes a dedicated WC Product Status column:

  • Displays the live status of the local WooCommerce product (Published, Draft, Pending Review, Private).
  • Updates immediately after background creation, bulk refresh, or webhook triggers.
  • Lets store managers audit catalog alignment between Shopify and WooCommerce at a single glance.

Reset to Default Mappings

To revert all custom assignments back to official Webkul recommendations:

  1. Select the Reset to Defaults button at the bottom left of the mapping card.
  2. A confirmation modal will appear:

    Reset Product Status Mapping?
    Are you sure you want to reset all product status mappings back to their default values? Any custom status assignments you have saved will be overwritten.

  3. Select Yes, Reset Defaults to confirm.
  4. The system restores the factory mapping (ACTIVE → publish, DRAFT → draft, ARCHIVED → draft) and displays "Product status mappings have been reset to default values successfully!".
