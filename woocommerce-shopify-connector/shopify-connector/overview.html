Overview

WooCommerce Shopify Connector turns WooCommerce into a control center for your Shopify store (or stores). Instead of configuring products and processing orders on both platforms separately, you connect Shopify once and move data in either direction from the WordPress admin.

What the connector does

Products. Import simple and variable Shopify products — including names, descriptions, images, prices, compare-at prices, SKUs, stock quantities, weights, tags, barcodes, and variant attributes — as native WooCommerce products. Export WooCommerce products to Shopify the same way, individually, in bulk, or automatically whenever a new product is published. With the Item-Wise Shopify Listing Editor, customize title, price adjustments, stock safety buffers, vendor, tags, barcodes, weights, HS tariff codes, country of origin, and field sync toggles per product and account. Bulk export or update directly from the WooCommerce Products table with a real-time modal progress queue.

Orders. Import Shopify orders into WooCommerce with the order status of your choice, filtered by date range or specific order IDs. Export WooCommerce orders to Shopify with one click, in bulk via toolbar actions, or automatically when customers check out. With Map Order Status, bidirectionally translate Shopify lifecycle, fulfillment, and financial payment states into WooCommerce order statuses. Core WooCommerce screens feature a real-time Shopify Sync column and single order Shopify Sync Details metabox with direct links and an instant sync button. Bi-directional fulfillment sync ensures that when an order is fulfilled in either WooCommerce or Shopify, tracking numbers, carriers, and links are synchronized automatically.

Store data. Import Shopify customers (as WooCommerce customer accounts), pages, coupons, blog posts, tax rates, and shipping zones so the WooCommerce side of your business matches Shopify without manual re-entry. Keep customer details synchronized in real time via automated customer update webhooks.

Category & collection mapping. Map multiple WooCommerce categories to Shopify collections in a dynamic multi-row mapper, ensuring catalogs stay organized on both storefronts.

Real-time sync & diagnostics. The connector registers 8 Shopify webhooks for order creation, order fulfillment, order update, customer update, real-time inventory level update, and product create/update/delete. Proactive Webhook Health Diagnostics monitor subscriptions and provide 1-Click self-healing repair. Combined with sync-direction settings, changes flow automatically, and you control exactly which product fields update in each direction.

Barcode & GTIN synchronization. Sync barcodes between Shopify and WooCommerce Core GTIN (_global_unique_id) or custom meta keys, with duplicate uniqueness enforcement to protect catalog integrity.

Pricing control. Price rules let you increase or decrease prices by a fixed amount or a percentage for products within a chosen price range, applied during import or export, per connected store.

Monitoring. The Sync Performance Dashboard tracks every product and order sync, showing success rates, failure counts, daily trend charts, and an error table with a suggested fix for each error code. A daily digest email summarizes the last 24 hours of sync activity.

How data flows

  1. You connect a Shopify store (OAuth via the Shopify Developer Dashboard, or a legacy custom-app token).
  2. Import actions pull data from Shopify into a staging area first, then a Create step turns staged records into real WooCommerce products, orders, users, or content — so you can review counts before anything is created.
  3. Export actions push WooCommerce records to Shopify and remember the link between the two, preventing duplicates.
  4. Webhooks notify WooCommerce the moment something changes on Shopify; a background queue processes those events automatically.
  5. Long-running jobs (large product imports, image downloads, product refreshes, bulk exports) run asynchronously in dedicated background queues with optimized memory utilization, displaying live progress row-by-row.

What the connector does not do

  • It does not create a customer-facing interface. Everything happens in the WordPress admin; your storefront is unchanged except for synced data (and Shopify tracking details on orders).
  • It does not sync product types other than Simple and Variable.

Requirements

Software Requirements

ComponentRequirement
WordPress6.7 or higher (tested up to 7.1)
WooCommerce10.0 or higher (tested up to 11.0) — must be active
PHP7.4 or higher (tested up to 8.4)
WordPress userAdministrator access

The plugin is compatible with WooCommerce High-Performance Order Storage (HPOS) and Cart/Checkout Blocks.

Shopify Requirements

  • A Shopify store (or stores) — simple plan or Shopify Plus.
  • A Shopify Developer Dashboard app providing the Client ID and Client Secret (created free in your Shopify Partners account) or a legacy custom app providing an Admin API access token.
  • The plugin's Redirect URI registered in your Shopify Developer app — shown with a copy button on the Add Account screen.

Background Processing

Real-time sync webhooks, automatic exports, and background refreshes run through WP-Cron. Make sure your site's cron is operating normally (it does by default on most hosts).
