Overview & System Requirements

WooCommerce POS Happy Hours Discount bridges promotional marketing and retail operations. The extension operates as a specialized add-on for the Webkul WooCommerce Point of Sale System, extending both the administrative back-office and the cashiers' single-page POS application.

Modern WooCommerce Compatibility

The plugin is fully compatible with WooCommerce High-Performance Order Storage (HPOS), utilizing native order tables for rapid order placement and database query optimization.

Architectural Overview

The plugin operates across two primary runtime tiers:

  1. Back-Office Management (WordPress Admin):

    • Registers configuration tabs within Point of Sale → Settings → Happy Hours.
    • Adds a dedicated management screen under Point of Sale → Happy Hours.
    • Maintains campaign schedules, eligible customer lists, and discount tiers in the database.

  2. Cashier Application (Point of Sale SPA):

    • Built on modern React and Redux state management.
    • Listens to core POS lifecycle hooks.
    • Fetches active Happy Hour configurations via asynchronous endpoints and updates the local POS memory store.
    • Calculates real-time discounts, adjusts line-item totals and taxes, and passes promotional metadata to completed order receipts.

Supported Product Types & Workflows

  • Simple Products: Instant fixed price deduction or percentage deduction.
  • Variable Products: Discounts calculate dynamically based on the selected variation price, automatically recalculating taxes proportionally.
  • Customer Restrictions: Supports open promotions for all shoppers or exclusive campaigns for selected registered users.
  • Offline / Sync Handling: When the terminal is refreshed or an order is completed, the discount states re-synchronize seamlessly with the server.
