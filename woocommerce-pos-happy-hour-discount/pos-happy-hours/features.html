Feature Highlights

WooCommerce POS Happy Hours Discount provides a comprehensive suite of features designed to simplify promotional scheduling for store administrators while keeping checkout fast and accurate for point-of-sale cashiers.

Administrative Features

1. Flexible Campaign Scheduling

  • Date Range Controls: Define precise starting and ending calendar dates for promotional periods.
  • Time Window Precision: Establish specific start times and end times down to the minute (e.g., 14:00 to 17:00).
  • Campaign Status Toggle: Quickly enable or disable rules with a single click without having to delete and re-enter configurations.

2. Multi-Tier Discount Application

  • Product-Level Discounts: Select individual products that receive promotional reductions.
  • Category-Wide Discounts: Target entire product categories (such as Apparel, Beverages, or Bakery) for automatic checkout discounts.
  • Cart Total Incentives: Set up minimum and maximum cart value thresholds (Cart From to Cart Till) that trigger promotional savings once reached.
  • Fixed vs. Percentage Deductions: Choose between a fixed dollar amount off (e.g., $5.00 off) or a percentage deduction (e.g., 15% off).
  • Multiple Rules per Campaign: Add multiple discount blocks within a single Happy Hour campaign using the intuitive Add discount action.

3. Customer Targeting

  • All Customers: Open promotional pricing to every counter shopper.
  • Select Customer(s): Restrict promotions to specific registered VIPs, loyal members, or wholesale accounts using an interactive multi-select search.

4. Customizable Terminal Labels

  • Store owners can customize the exact text strings presented on the register:
    • Countdown Timer Text: Replaces the default widget header.
    • Happy Hour Title: Specifies the promotional headline printed on order receipts.
    • Happy Hours Discount Fee Title: Defines how total cart deductions appear in payment breakdowns.
    • Happy Hour Discount Text: Labels the discount lines shown in cart items.

Cashier Terminal Features

1. Live Header Countdown Timer

  • An interactive timer widget resides permanently in the top-right header of the POS terminal during active Happy Hours.
  • Displays remaining time in standard format: DDd:HHh:MMm:SSs.
  • Allows the cashier to expand or collapse the timer badge to save screen real estate during busy rushes.

2. Customer Discount Eligibility Indicator

  • Opening the POS Customers menu shows a dedicated badge reading Apply For Happy Hours Discount beside every qualified customer.
  • Provides immediate visual confirmation to the cashier before beginning an order.

3. Automatic Price Deductions in Cart

  • When a promotional product is added to the cart, the unit price automatically drops to the discounted rate.
  • Displays the original price struck through alongside the new price and an explicit -$X.XX Discount tag.
  • Taxes dynamically recalculate based on the net promotional unit price.

4. Structured Discount Priority

  • When multiple rules or items coincide, the plugin enforces a reliable priority order: $$\text{Product Discount} \longrightarrow \text{Category Discount} \longrightarrow \text{Cart Total Discount}$$
  • Eliminates accidental double-discounting while guaranteeing predictable counter margins.

5. Mid-Order Customer Protection Guard

  • If a cashier attempts to switch the assigned customer while items are already in the cart during active Happy Hours, the system alerts the cashier:

    Note: Happy hours are started, so the cart must be empty to update the customer.

  • Prevents price tampering or accidental eligibility mismatches.

6. Transparent Payment & Invoice Breakdown

  • The POS payment tender screen displays the Happy Hours discount line before processing cash or card payments.
  • Printed POS receipts and digital invoices prominently print the discount headline and saved amount, reinforcing customer satisfaction.

Technical & Infrastructure Highlights

  • HPOS Ready: Built and verified for WooCommerce High-Performance Order Storage.
  • Multisite Compatible: Full support for network-wide activation and automatic schema creation across WordPress multisite networks.
  • Zero Front-End Clutter: Operates cleanly within the POS interface without injecting unwanted scripts onto public online storefront pages.
