FAQ & Troubleshooting

This section provides verified answers to common questions and actionable troubleshooting steps for error messages encountered during setup and daily operations.

Frequently Asked Questions

Does the plugin require third-party AI accounts?

Yes. Virtual Try On relies on generative AI vision models to perform human model generation and garment drape rendering. You must supply an API key from Google Gemini (Google AI Studio), OpenAI, Alibaba Cloud Qwen (DashScope), or a custom API endpoint.

Are my AI API keys secure?

Yes. API keys are stored encrypted on your server backend. The frontend browser never communicates directly with third-party AI APIs; all generation requests transit through the authenticated WordPress REST API endpoint (/wp-json/wkvton/v1/generate-image), ensuring your API keys are never exposed in client source code or network inspector panels.

Which product types are supported?

Virtual Try On works seamlessly on both Simple products and Variable products under WooCommerce.

Can guest visitors use virtual try-on without logging in?

Yes, if enabled by the store administrator. In Webkul WC Addons → Virtual Try On, set Allow Virtual Tryon For Guest Users to Allow. If set to Disallow, only logged-in customer accounts see the try-on button.

Does the plugin support WooCommerce High-Performance Order Storage (HPOS)?

Yes. The plugin explicitly declares compatibility with custom_order_tables and functions seamlessly on stores utilizing HPOS.

Can I generate images for my product gallery without extra tools?

Yes. Open any product in WordPress Admin, locate the Virtual Tryon sidebar metabox, click Click to try this image, generate an AI visual, and click Yes to save the picture directly into the WooCommerce product image gallery.

Troubleshooting & Error Messages

Symptom: The "Click to try this product" button is not appearing on the store page

Verified Causes & Resolution:

  1. Global Plugin Status: Check Webkul WC Addons → Virtual Try On and verify Virtual Try On Status is set to Enable.
  2. Product-Level Status: Open the product edit page, check the Virtual Try On tab, and confirm Virtual Tryon Status is set to Enable.
  3. Guest Policy: If testing while logged out, ensure Allow Virtual Tryon For Guest Users is set to Allow.
  4. Missing Featured Image: Verify that the product has a featured thumbnail image assigned.

Error: "Kindly upload the product image to apply virtual tryon."

  • Cause: An administrator clicked the try-on button in the product edit sidebar metabox, but the product has no featured thumbnail assigned.
  • Resolution: Upload a clear featured image in the Product image panel, update the product, and reopen the try-on modal.

Error: "Api Key cannot be empty."

  • Cause: The plugin was saved with Virtual Try On Status set to Enable under Gemini, OpenAI, or Qwen, but no API key was provided.
  • Resolution: Obtain a valid key from your AI provider (see AI Provider Setup), enter it into the provider's key field, and click Save Configuration.

Error: "Please enter a valid base URL."

  • Cause: The Custom AI provider was selected without a valid HTTP or HTTPS endpoint URL.
  • Resolution: Enter the complete base URL of your AI service (e.g., https://api.example.com/v1) and save.

Error: "Model name contains invalid characters."

  • Cause: A custom model name included unsupported punctuation or spaces.
  • Resolution: Restrict model identifiers to alphanumeric characters and standard delimiters (A-Z, a-z, 0-9, ., -, _, +, /, @).

Error: "Image size exceeds the maximum limit of %s."

  • Cause: A generated image or uploaded personal photo exceeded the WordPress upload threshold or the limit defined by the wkvton_max_gallery_image_size hook.
  • Resolution: Increase your PHP upload_max_filesize and post_max_size in php.ini, or adjust the filter in your child theme's functions.php:
    add_filter( 'wkvton_max_gallery_image_size', function() {
    return 10 * MB_IN_BYTES; // Increase to 10 MB
});

Error: "Only JPG, PNG, and WebP images are allowed."

  • Cause: A customer attempted to upload a file in an unsupported format (e.g. BMP, TIFF, HEIC, PDF).
  • Resolution: Advise the customer to upload a standard JPG, PNG, or WebP photo.

Error: "Something went wrong please try again later"

  • Cause: The upstream AI provider rejected the request due to an expired API key, exhausted billing quota, network timeout, or content moderation filter.
  • Resolution:
    1. Verify your provider account billing balance and quota limits in Google AI Studio, OpenAI, or Alibaba Cloud console.
    2. Test fetching models using the Refresh button in the settings panel to confirm credentials are active.
    3. Ensure your server firewall allows outbound HTTPS traffic on port 443.
