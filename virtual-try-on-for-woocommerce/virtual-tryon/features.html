Feature Highlights

1. Multi-Provider AI Engine & Dynamic Discovery

Store owners are not locked into a single AI vendor. The plugin natively integrates with three top-tier commercial vision providers and allows arbitrary private endpoints:

  • Google Gemini: Integrates with Google AI Studio image generation models (such as gemini-2.5-flash-image, gemini-3.1-flash-image, and preview models).
  • OpenAI: Integrates with OpenAI image generation and editing models.
  • Alibaba Cloud Qwen: Leverages DashScope image editing models (qwen-image-edit).
  • Custom Endpoints: Allows connecting private proxies, enterprise gateways, or self-hosted Stable Diffusion / FLUX pipelines with selectable format compatibility (OpenAI compatible, Gemini compatible, or Qwen compatible).
  • Live AJAX Refresh: Fetch active models available under your account credentials without manual configuration file edits.

2. Dual Customer Try-On Modes

Shoppers can choose the try-on path that suits their comfort and preferences:

  • AI Generated Model (Demographic Simulation): Customers customize a virtual model by selecting their country of origin, target age (5 to 100), gender (Male or Female), body build type (Small, Mid, Plus), and skin complexion across 8 realistic tones (Very Fair, Fair, Light, Medium, Tan, Brown, Dark Brown, Deep).
  • Own Model (Personal Photo Fitting): Customers upload a front-facing full-body photo. The AI overlays the garment accurately onto their physique, maintaining facial identity, hand position, and posture intact.

3. Admin Catalog Visuals Generator

Building catalog imagery with human models typically requires costly photography, agency hiring, and editing delays. The Admin Gallery Generator allows store managers to:

  • Open the Virtual Try On modal directly on the WordPress product edit page.
  • Select desired model parameters (e.g. female model, medium build, olive skin).
  • Generate a visual try-on image.
  • Confirm the generation prompt: "Save this picture in the product gallery".
  • Automatically sideload the image into the WordPress Media Library and attach it to the WooCommerce product image gallery without leaving the dashboard.

4. Bulk Operations

For merchants managing hundreds of products, the plugin adds dedicated bulk actions under Products → All Products:

  • Enable Virtual Tryon Status: Immediately enables the feature across all selected products.
  • Disable Virtual Tryon Status: Immediately turns off the feature across all selected products.

5. Architectural Security & Performance

  • Zero Client Credential Exposure: API keys are securely encrypted using XOR and dynamic salt strings, stored exclusively on the server, and decrypted solely for backend outbound API calls.
  • Payload & Memory Protection: Sideloaded images undergo strict Base64 structure checks, MIME type verification (JPEG, PNG, GIF, WebP), and file size enforcement against wkvton_max_gallery_image_size.
  • High-Performance Order Storage (HPOS): Fully certified for modern WooCommerce installations utilizing dedicated custom order tables.
