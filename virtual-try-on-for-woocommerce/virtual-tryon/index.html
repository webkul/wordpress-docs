Virtual Try On for WooCommerce

Virtual Try On for WooCommerce is an advanced AI-powered fitting room solution that allows customers to preview clothing and apparel products directly on custom virtual models or their own uploaded photographs prior to purchasing.

By enabling visual verification of garments on real-world body types and skin tones, the extension eliminates customer guesswork, boosts buyer confidence, and dramatically reduces product return rates.

Documentation Journey

Follow the merchant journey below to install, configure, and maximize the Virtual Try On extension on your WooCommerce store:

  1. Overview — Learn about core concepts, supported apparel types, system requirements, and architecture.
  2. Features — Explore the complete feature breakdown across administration and customer storefronts.
  3. Installation — Step-by-step instructions to upload, install, and activate the plugin via WordPress admin.
  4. Admin Configuration — Set up global try-on status, guest user permissions, and AI provider credentials.
  5. AI Provider Setup — Detailed instructions on obtaining API credentials for Google Gemini, OpenAI, Alibaba Cloud Qwen, or custom endpoints.
  6. Product Configuration — Configure try-on options, model selection, gender restrictions, and prompt customization per product.
  7. Bulk Product Management — Efficiently manage try-on status for dozens of products simultaneously using WooCommerce bulk actions.
  8. Admin Gallery Generator — Generate AI visual previews right from the product editor and save them directly to your WooCommerce product gallery.
  9. Customer Workflow — The shopper's experience from the product page button to the interactive try-on modal and photo upload.
  10. User Guide & Blog Walkthrough — Comprehensive narrative walkthrough and feature showcase for merchants and marketing teams.
  11. FAQ & Troubleshooting — Verified resolutions for common questions, error messages, and support channels.
