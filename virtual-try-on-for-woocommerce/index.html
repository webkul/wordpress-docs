Why Virtual Try On is the complete apparel fitting solution

Bring interactive AI fitting rooms to product pages and empower customers to preview clothing on tailored models or their personal images.

AI Virtual Fitting Room
Customers preview upper and lower body apparel directly on customized virtual human models with automatic clothing alignment and accurate lighting.
Multi Provider AI Architecture
Connect Gemini, OpenAI, Qwen, or any custom API endpoint with dedicated credentials, allowing store owners to select preferred visual generation models.
Dynamic Model Discovery
Query active AI provider endpoints in real time to fetch supported image generation models with a single click from the WordPress admin configuration.
Custom Photo Upload Try On
Shoppers can upload their personal front facing photos to see products fitted accurately on their own body without changing poses or facial features.
Admin Catalog Gallery Generator
Generate realistic AI model visuals from the product editor and save them directly to the WooCommerce product gallery for enhanced catalog marketing.
Granular Prompt Customization
Control prompt templates with dynamic variables for gender, age, skin tone, country, and body type, tailoring visual generation to brand aesthetics.
Bulk Product Status Controls
Enable or disable virtual try on across dozens of apparel items simultaneously using standard WooCommerce product list bulk action menus.
Flexible Guest Shopper Access
Choose whether to permit instant try on previews for first time guest visitors or restrict access exclusively to registered customer accounts.
Secure Server Side API Execution
API keys remain encrypted and stored strictly on the server backend, executing generation requests securely without exposing secret credentials to client browsers.

What's New in v1.1.0

  • Multi-Provider AI Architecture — Added support for leading AI vision providers including Google Gemini, OpenAI, Alibaba Cloud Qwen, and Custom third-party endpoints. Provider Setup Guide →
  • Dynamic Model Discovery via AJAX — Automatically fetch available image generation models directly from provider APIs with an in-page Refresh action. Model Discovery Guide →
  • Custom Endpoint & Format Adapters — Store owners can connect private AI proxies and local models using OpenAI compatible, Gemini compatible, or Qwen format adapters. Custom Endpoint Guide →
  • Separate API Credentials per Provider — Store independent API keys and default image models per provider, with automatic migration of legacy configurations. Credentials Guide →
  • Direct Product Gallery Sideload — Administrators can generate try-on images directly inside the product edit screen and attach them to the WooCommerce gallery with one click. Gallery Generator Guide →
  • Bulk Product Status Controls — Enable or disable virtual try-on across dozens of catalog products in seconds using native WooCommerce bulk actions. Bulk Management Guide →
  • Developer Filters for Providers & Models — Extend supported providers and modify listed image models programmatically via wkvton_modify_providers_list and wkvton_modify_listed_models hooks. Developer Hooks Guide →
  • WordPress 6.9 & WooCommerce 10.3 Compatibility — Full support for WooCommerce High-Performance Order Storage (custom order tables), strict base64 image validation, and PHP 8.4 verification. System Requirements →
