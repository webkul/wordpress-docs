Import Products

Importing brings your Shopify catalog into WooCommerce as fully functional WooCommerce products, complete with pricing, variations, images, categories, and inventory tracking.

Open Manage Account → Products → Import Product.

Before You Import

Ensure your store synchronization preferences are configured in General Settings:

  • Products to Import: Choose All products or Only mapped categories product.
  • Products to Import having Shopify Status: Restrict to Active, Draft, or Archived items.
  • Import Only In-Stock Products: Skip zero-stock items automatically.
  • Import Products As: Set the initial WooCommerce status (Published, Draft, or Pending Review).
  • Default Category: Where unmapped products are filed.
  • Prevent Duplicate Products (Import): Choose Update product if SKU exist and product not synced to merge and update existing WooCommerce products sharing the exact same SKU.
  • Product Image Import: Choose In The Background to create catalog items instantly while media assets download asynchronously.

Advanced Import Filters

The connector provides three flexible import selection modes:

  1. Import All: Queries your Shopify store and imports the entire eligible catalog in paginated batches.
  2. Import By ID: Target specific products by entering one or more numeric Shopify Product IDs. The connector features intelligent delimiter auto-detection supporting commas (,), semicolons (;), colons (:), and vertical bars (|).
  3. Import Date Wise: Select From Date and To Date to import only products published or modified within a specific date range.

Two-Stage Import & Queue Processing

To guarantee data safety and give merchants complete visibility, the import workflow operates in two stages powered by WordPress Action Scheduler:

Stage 1: Import Product (Fetch & Stage)

Select Import Product. The connector queries Shopify GraphQL Admin API, discovers products matching your filters, and stages them into the local connector database.

Stage 2: Create Imported Products

Once discovery completes, the Create Imported Products (N) button activates, displaying the number of staged items ready for catalog insertion. Selecting it enqueues the creation jobs into the background queue.

[!NOTE] Non-blocking background processing: Imports execute asynchronously in the background. You do not need to keep your browser tab open. You can safely navigate away, and the queue worker will continue processing.

Interactive Queue Card Interface

The Queue Card appears at the top of the screen whenever background import or export jobs are queued or running:

  • Progress Bar: Real-time visual progress showing completed (green), failed (red), and cancelled (gray) segments.
  • Live Status Counters:
    • Queued / Pending: Items waiting for the next worker batch.
    • Processing: Items currently being parsed and written to the database.
    • Imported / Success: Successfully imported WooCommerce products.
    • Skipped: Products skipped due to stock filters or duplicate SKU rules.
    • Failed: Items encountering Shopify API timeouts or database validation errors.
    • Cancelled: Jobs stopped manually by the vendor.
  • Run History (Latest 20): A dropdown selector allowing you to inspect past runs by Run ID, phase, execution state, and date/time.
  • Queue Controls:
    • Retry failed (N): Immediately retries only the failed items from the active run without repeating successfully processed records.
    • Cancel (N): Immediately halts active background tasks.
    • Clear run history: Purges completed and archived job logs.

Refresh Products (On-Demand Catalog Sync)

To synchronize remote catalog adjustments without initiating a full import, select Refresh Products in the action bar.

A confirmation dialog details the action:

  • Scans all mapped WooCommerce products linked to this Shopify account.
  • Queries Shopify for updated prices, stock levels, titles, descriptions, and barcodes.
  • Applies updates directly to the WooCommerce catalog without re-creating products or duplicating image attachments.
  • Select Refresh to launch the non-blocking background refresh queue.

The Imported Product List

Every product imported for this Shopify account appears in the responsive data table:

ColumnInformation & Actions
Thumbnail & ProductProduct image, WooCommerce product ID, product type (Simple, Variable), and direct links to Edit, Edit Shopify Listing, and Delete.
Shopify IDDirect hyperlink to view and manage the product inside the Shopify Admin (https://<store>.myshopify.com/admin/products/<id>).
Exclusion SwitchOne-click toggle switch to instantly exclude or include this specific product from future real-time synchronization.
Row Details ToggleExpands collapsible product metadata, variant attributes, and synchronization timestamps.

Single Product Actions

  • Edit: Opens the standard WCFM product edit screen.
  • Edit Shopify Listing: Opens the dedicated Shopify Listing Editor to customize titles, descriptions, prices, barcodes, and images specifically for Shopify without altering your WooCommerce catalog.
  • Delete: Breaks the connection for this product. A confirmation modal confirms that the link is removed, but the product is not deleted from Shopify.

Bulk Table Actions

Select multiple products using the checkboxes and apply bulk actions:

  • Update From Shopify: Fetches remote changes from Shopify and updates the selected WooCommerce products.
  • Update in Shopify: Pushes local WooCommerce changes for selected products to Shopify.
  • Exclude from Sync: Marks selected products as excluded from automated sync.
  • Include in Sync: Restores selected products to active synchronization.
  • Delete: Removes connector mapping records for selected products.

Understanding Catalog Operations

To prevent confusion, distinguish between the four catalog synchronization actions:

ActionDirectionPurpose
Import from ShopifyShopify → WooCommerceCreates new WooCommerce products from Shopify catalog items.
Update from ShopifyShopify → WooCommerceRefreshes existing WooCommerce products with latest Shopify data.
Export to ShopifyWooCommerce → ShopifyCreates new Shopify products from WooCommerce catalog items.
Update in ShopifyWooCommerce → ShopifyPushes WooCommerce catalog adjustments up to Shopify.
