Webhooks & Diagnostics

Webhooks are automated HTTP notifications sent by Shopify to your WordPress server whenever an event occurs (such as a customer placing an order or a merchant editing a product). Webhooks power the real-time synchronization engine of WCFM Marketplace Shopify Connector.

Open Manage Account → Settings → Webhooks.

Webhook Health Diagnostic & 1-Click Repair

The connector provides a dedicated Webhook Health Diagnostic & 1-Click Repair interface to test, verify, and automatically repair webhook endpoints without requiring manual reconfiguration.

Key Diagnostic Features

  • Live Health Status Badge: Displays a color-coded status badge:
    • Healthy: All required Shopify webhook subscriptions are active and responding cleanly.
    • Action Required (N Issues): Highlights missing subscriptions, invalid callback URLs, or broken endpoints.
  • 1-Click Repair Webhooks: If any webhooks are missing, deleted, or pointing to an obsolete site URL, select 1-Click Repair Webhooks. The connector queries the Shopify GraphQL API and immediately recreates all required subscriptions.
  • Re-Check Now: Forces a live audit against the Shopify Admin API, bypassing local cache to verify current webhook health on demand.

Core Webhook Subscriptions

The connector automatically registers five essential webhook subscriptions with your Shopify store:

Webhook EventTopic NamePurpose in Synchronization
Order CreationORDERS_CREATECaptures newly placed customer purchases on Shopify and automatically imports them into WooCommerce when Auto Import Order is enabled.
Order UpdatesORDERS_UPDATEDCaptures Shopify order cancellations, financial payment status changes, restocks, and carrier tracking numbers, updating corresponding WooCommerce orders.
Product CreationPRODUCTS_CREATEDetects newly published Shopify products and triggers automatic catalog imports when Auto Import Product is enabled.
Product UpdatesPRODUCTS_UPDATECaptures real-time price changes, inventory adjustments, and catalog edits on Shopify and syncs them to WooCommerce.
Product DeletionPRODUCTS_DELETEDetects when a product is removed from Shopify and executes your configured Auto Delete rule in WooCommerce.

[!NOTE] The diagnostic suite also validates related synchronization subscriptions, including inventory level updates (INVENTORY_LEVELS_UPDATE), ensuring warehouse stock adjustments propagate cleanly across locations.

HMAC SHA-256 Cryptographic Verification

To protect your marketplace against unauthorized tampering and spoofing, the connector enforces HMAC SHA-256 signature verification on all incoming webhook requests:

  1. Every incoming HTTP request from Shopify contains the header X-Shopify-Hmac-Sha256.
  2. The connector computes an HMAC hash of the raw payload using your store's private API secret key.
  3. If the calculated signature matches the incoming header, the webhook is verified and processed.
  4. If the signature is invalid or absent, the request is rejected immediately with a 401 Unauthorized HTTP status, ensuring that fake or malicious payloads cannot alter store data.

Managing and Repairing Webhooks

Webhook endpoints are managed and maintained automatically through the connector's 1-Click diagnostic system:

  • 1-Click Repair: If webhook subscriptions in Shopify become out of sync, broken, or point to an older URL following a domain migration, select 1-Click Repair Webhooks. The connector queries the Shopify Admin API, validates callback URLs, and recreates any missing or damaged endpoints in one operation.
  • Account Disconnection: When you disconnect or remove a Shopify store under Shopify Accounts, the connector automatically deregisters and deletes all associated webhooks from Shopify, ensuring no orphaned background events continue firing to your server.
  • Diagnostics on Demand: Use Re-Check Now at any time to execute an instant health audit against Shopify to confirm all subscriptions are live and healthy.

[!NOTE] Webhooks are required for real-time background synchronization. If webhooks are ever inactive, manual imports and exports remain completely functional while you re-run 1-Click Repair.

Issue / Error MessagePotential CauseHow to Resolve
Shopify token is invalidAPI access token has expired, been revoked, or scopes changed in Shopify.Reconnect the account from the Shopify Accounts page or re-authorize via the Setup Wizard.
Action Required (Issues Found)Webhook subscriptions were removed in Shopify or the site URL changed.Click 1-Click Repair Webhooks to re-register subscriptions automatically.
No Data FoundNo webhooks currently exist on Shopify.Click 1-Click Repair Webhooks to generate all five core subscriptions.
401 Unauthorized in Shopify logsWebhook HMAC verification failed due to mismatched API credentials.Verify your Shopify App Secret Key in the account configuration screen.
