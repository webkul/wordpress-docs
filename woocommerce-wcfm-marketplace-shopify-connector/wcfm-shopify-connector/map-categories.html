Category Mapping

Category mapping links your WooCommerce store categories to your Shopify collections. When products are imported or exported, the connector evaluates these mappings so products land in their correct catalog taxonomy rather than falling back into a generic default category.

Open Manage Account → Map Categories.

Why Category Mapping is Essential

  • Targeted Product Import: In General Settings, setting Products to Import to Only mapped categories product restricts imports exclusively to products in mapped collections.
  • Accurate Catalog Organization: Even when importing your entire catalog, category mapping ensures imported products appear under the exact product categories your customers browse on WooCommerce.
  • Shopify Collection Assignment on Export: Exported WooCommerce products are automatically added to their corresponding Shopify collections based on active mappings.
  • Persistent Mapping Integrity: Category mappings are strictly persisted in the database and retained throughout real-time updates and bulk queue operations.

The Modern Multi-Row Mapping Interface

The connector features a streamlined multi-row mapping table that allows vendors to map multiple categories and collections in a single submission, complete with hierarchical breadcrumbs and in-page conflict validation.

Step-by-Step Workflow

  1. Fetch Shopify Collections: Select the Fetch Shopify Collections button in the header. The connector queries the Shopify GraphQL Admin API and syncs all manual and automated collections from your connected Shopify store.

  2. Select WooCommerce Category (Hierarchical Selector): The WooCommerce category dropdown formats your store's taxonomy hierarchically:

    • Full breadcrumb paths (e.g., Clothing → Men's → Hoodies) clarify categories that share identical child names.
    • Subcategories are indented according to their tree depth.
    • Categories already mapped to this Shopify account are flagged with — Already mapped and disabled, preventing duplicate or conflicting rules.

  3. Select Shopify Collection: Choose the target collection from the right-hand dropdown. Each collection displays its human-readable title alongside its numeric Shopify collection ID (e.g., Summer Collection (#2849182390)).

  4. Add Multiple Rows: Select + Add another row to create additional mapping pairs in the same form. You can stage as many category-to-collection pairs as needed. Use the trash button on the right of any row to remove an unwanted pair before saving.

  5. Save Mappings: Select Save Mappings. The connector validates all selected pairs for conflicts, commits the records to the database, and displays a success notification confirming how many categories were mapped.

Discarding Unsaved Mappings

If you make changes or add rows but choose not to proceed, select Cancel.

A safety modal dialog appears asking: Discard unsaved mappings?

  • Select Cancel to return to editing your staged rows.
  • Select Discard to clear all unsubmitted rows and restore the saved mapping state.

Managing Existing Mappings

All active category associations are displayed in the Category Mapping Table beneath the creation form:

ColumnInformation Displayed
Store CategoryThe WooCommerce product category name and slug.
Shopify Collection IDUnique numeric identifier for the collection on Shopify.
Shopify CollectionHuman-readable title of the mapped Shopify collection.
Published at ShopifyTimestamp when the collection was created/published in Shopify.

Searching and Filtering

Use the Search input above the table to quickly locate mappings by collection name or category title.

Removing Mappings

To delete one or more mappings:

  1. Check the box next to each category mapping you wish to remove (or use the master checkbox in the header).
  2. Choose Delete from the Bulk actions dropdown.
  3. Select Apply.

A confirmation notice will read Category Deleted Successfully.

[!NOTE] Deleting a category mapping breaks the association between the WooCommerce category and Shopify collection for future synchronizations. It does not delete categories in WooCommerce or collections in Shopify, nor does it delete products already assigned to them.

Handling Validation & Error Messages

MessageRoot CauseRecommended Action
Category already mapped.The selected collection or WooCommerce category is already assigned.Select a different category, or delete the existing mapping entry from the table below before remapping.
Mapping conflict: this WooCommerce category or Shopify collection is already mapped.A duplicate selection was attempted across staged rows.Review your staged rows and ensure each category and collection appears only once.
Please select a valid category to map.One or both dropdowns in an active row were left blank.Select both a WooCommerce category and a Shopify collection before clicking Save Mappings.
You are not authorized to map categories for this store.User permissions mismatch or invalid vendor account session.Verify you are logged into your designated vendor account and that the store connection is active.
