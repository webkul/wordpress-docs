Changelog & Version History

Complete release notes, feature additions, fixes, and optimizations across every release of WooCommerce WCFM Marketplace Shopify Connector.

v4.0.0

Latest Release
2026-11-17
  • AddedDedicated "Edit Shopify Listing" interface with custom product overrides for Title, Description, Price, Compare-at Price, Barcode, SKU, Images, and Stock without modifying WooCommerce catalog.
  • AddedCustom Shopify gallery curation with media library selection, drag-and-drop reordering, and variation-specific image customization.
  • AddedBidirectional real-time product synchronization ("Both ways") keeping catalogs aligned simultaneously.
  • Added"Auto Export Product" setting to automatically export newly published WooCommerce products to Shopify in the background.
  • Added"Import Only In-Stock Products" filter and bidirectional "Auto Delete" options for synchronized products.
  • AddedDedicated "Map Product Status" tab to map Shopify statuses (Active, Draft, Archived) to WooCommerce post statuses.
  • AddedDedicated "Map Order Status" tab with bidirectional order sync settings (Auto Import, Auto Export, Update Sync, and Fulfillment Sync).
  • AddedGranular "Fields to Sync" settings in General Configuration (Title, Description, Images, Price, Categories, Weight, Barcode, SKU, Inventory, Status, and Tags).
  • AddedProduct Exclusion System with interactive AJAX search and single-click row exclusion toggles.
  • Added"1-Click Webhook Diagnostic & Repair" tool with automated subscription verification and endpoint healing.
  • AddedAction Scheduler Background Queue Card with live progress counters (Queued, Processing, Completed, Skipped, Failed), latest 20 runs history, and 1-click retry.
  • AddedMulti-Row Category Mapping Table with hierarchical breadcrumbs, conflict detection, and unsaved changes discard modal.
  • AddedCryptographic HMAC SHA-256 webhook signature verification to prevent unauthorized webhook spoofing.
  • Added"Refresh Product" button in product tables to pull latest remote Shopify catalog changes on demand.
  • ImprovedProduct and Order tables UI with modernized status badges, direct Shopify links, and imported order counter.
  • ImprovedLocked Shopify API integration to version 2026-10 with missing OAuth scope warning banners and full HPOS compatibility.
  • FixedLocation-based stock synchronization and baseline tracking to eliminate double stock deduction during concurrent checkout and inventory sync.
  • FixedRepeated image uploads and duplicate gallery images during real-time product synchronization.

v3.0.1

2026-09-15
  • ImprovedProduct images are only re-imported when they actually change on Shopify.
  • ImprovedOrder export now runs in the background via Action Scheduler instead of blocking checkout.
  • FixedDuplicate background sync workers no longer start for the same queue.
  • FixedA worker that dies mid-batch no longer replays completed items or retries a failing one forever.

v3.0.0

2026-08-25
  • AddedNew guided Setup Wizard for connecting a Shopify account (store info, API credentials, and one-click connect).
  • AddedRedesigned UI for Account List, Add/Manage Account, Map Categories, Price Rule, Settings, and vendor Product/Order tables.
  • AddedBackground processing of product/order import, export, and image sync using Action Scheduler.
  • AddedJavaScript strings are now translatable via WordPress i18n standards.
  • AddedConfirmation modals before deleting accounts and mapped records.
  • ImprovedTable views and responsive pagination for product, order, and category listings.
  • ImprovedCertified compatibility with WooCommerce 11.0 and WordPress 7.1.
  • ImprovedSecurity hardening and WordPress coding standards updates.
  • FixedReal-time product sync (price, stock, status) and image sync edge cases.
  • FixedProduct import/export and order export/import handling for missing or malformed Shopify data.
  • FixedResolved stuck background processing jobs.
  • FixedDebounced rapid-fire repeated Shopify product-update webhooks.

v2.1.0

2026-01-14
  • AddedPrice rules for imported and exported products (fixed and percentage markups/discounts).
  • AddedAdmin visibility for vendor webhook generation status from the Admin Vendor Account List.
  • ImprovedUpgraded connector requests to Shopify GraphQL Admin API.
  • ImprovedModernized authentication flow compatible with Shopify Developer Dashboard.
  • ImprovedCertified compatibility with WordPress 6.9 and WooCommerce 10.4.

v2.0.0

2025-04-15
  • AddedWebkul software licensing integration and purchase-code verification.
  • AddedAdmin setting to configure which image sizes are generated during WooCommerce product imports.
  • ImprovedTransitioned core catalog endpoints to Shopify GraphQL.
  • ImprovedCertified compatibility with WordPress 6.7 and WooCommerce 9.8.
  • OptimizedMinified frontend scripts and consolidated stylesheets for faster loading times.

v1.2.0

2024-11-26
  • AddedChoice between immediate image download and asynchronous background image import during product creation.
  • AddedReal-time order export based on specific WooCommerce order statuses.
  • AddedReal-time account connection status indicator for vendors and administrators.
  • ImprovedSeparate views for exported and non-exported products and orders.
  • ImprovedDisplay imported Shopify orders in the main WCFM orders list.
  • ImprovedRenamed "Category" buttons to "Collections" for Shopify terminological parity.
  • FixedProduct quantity and stock status management from Shopify updates.
  • FixedPagination and search under import and export order tables.
  • FixedPrevented exported products from appearing under imported product lists for the same vendor.
  • FixedResolved incorrect vendor order assignment when customers purchase products from multiple vendors.
  • FixedVariable product single simple item splitting issues.
  • FixedResolved theme layout conflicts with third-party WooCommerce themes.
  • FixedCapability checks and security hardening on all vendor AJAX endpoints.

v1.1.0

2024-07-10
  • AddedDynamic webhook registration and dedicated Webhooks management sub-tab.
  • AddedBackground workers for product image imports and auto-sync requests.
  • Added"Update From Shopify" on-demand product refresh action.
  • AddedInteractive loader and progress feedback during sync operations.
  • AddedAdministrator overview menu displaying all connected vendor accounts.
  • AddedHigh-Performance Order Storage (HPOS) compatibility.
  • AddedHelp tooltips across all configuration forms.
  • FixedSale price and regular price mapping edge cases.
  • FixedPrevious product details overwriting on import.
  • FixedSecurity hardening and nonce verification.

v1.0.0

Initial Release
2024-03-05
  • AddedInitial release of WooCommerce WCFM Marketplace Shopify Connector.
  • AddedMulti-vendor Shopify store connections to individual WCFM vendor accounts.
  • AddedManual and automated product import and export between Shopify and WooCommerce.
  • AddedManual and automated order import and export with order status mapping.
  • AddedCategory mapping between WooCommerce product categories and Shopify collections.
  • AddedBidirectional stock and price synchronization.
  • AddedVendor shipping and fulfillment management for exported orders from Shopify.
