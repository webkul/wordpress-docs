Features

Everything listed here is implemented and verified on a live WCFM marketplace running version 4.0.0.

Connecting Shopify Stores

  • Connect a Shopify store using a modern Developer Dashboard App (OAuth 2.0) or a legacy custom app (Admin API token).
  • Connect multiple Shopify stores to the same vendor account and seamlessly switch between them using the integrated store switcher without losing context.
  • Guided four-step Setup Wizard collects store details, validates credentials, and completes authorization in minutes.
  • Copy Setup URI and Copy Main URI buttons provide the exact redirect URIs required by the Shopify app configuration.
  • Real-time Connected / Disconnected health status for every account, refreshed asynchronously.
  • Missing OAuth scope warning banners alert vendors if critical API scopes are missing from their Shopify app.
  • Powered by modern Shopify GraphQL Admin API version 2026-10.

Dedicated "Edit Shopify Listing" Interface

  • Customize product listings specifically for Shopify without altering the core WooCommerce product catalog.
  • Override Title, Description, Price, Compare At Price, SKU, Tags, and Barcodes per product.
  • Custom Shopify Media & Gallery Curation: Switch between the WooCommerce catalog gallery and a custom Shopify gallery with media library selection, variation-specific image assignments, and drag-and-drop reordering.
  • Per-location Shopify inventory quantity overrides.
  • Single-click Reset Shopify overrides to restore direct inheritance from the WooCommerce catalog.

Products & Catalog Synchronization

  • Non-Blocking Background Processing: Bulk product imports and exports operate via WordPress Action Scheduler. Vendors can safely navigate away while processing continues.
  • Interactive Queue Card: Live progress bar with color-coded segments, real-time counters (Queued, Processing, Completed, Skipped, Failed, Cancelled), 20-run history selector, and controls to cancel running jobs or retry failed items.
  • Advanced Import Filters: Select between Import All, Import By ID (with delimiter auto-detection for commas, semicolons, colons, or pipes), and Import Date Wise (From and To date ranges).
  • Import Only In-Stock Products: Automatically skips zero-inventory items during Shopify catalog imports.
  • Prevent Duplicate Products (SKU Matching): Choose whether matching SKUs trigger new product creation or link and update existing catalog items during import and export.
  • "Refresh Products" on Demand: Query remote Shopify catalog adjustments and update prices, inventory, titles, and barcodes without creating duplicates.
  • Bulk Catalog Actions: "Update From Shopify" and "Update in Shopify" bulk operations with background progress tracking.
  • Product Exclusion System: Live AJAX search to exclude specific WooCommerce products from bulk/auto exports, interactive tag-box inputs for Shopify Product ID and SKU exclusions, and instant one-click toggle switches in product tables.
  • Bidirectional Auto-Delete: Configure whether deleting a product in one store moves the corresponding item to trash, permanently deletes it, or leaves it unaffected in the other.

Orders & Fulfillment Synchronization

  • Action Scheduler Order Queue: Non-blocking background import and export of orders with live status counters and retry capabilities.
  • Two-Stage Order Import: Discover and stage orders, then create WooCommerce transactions with dynamic pending count badges.
  • Order Status Mapping: Comprehensive mapping between Shopify Order Lifecycle (Cancelled), Fulfillment (Fulfilled, Unfulfilled, Partially Fulfilled, On Hold, Restocked), and Financial (Paid, Pending, Authorized, Partially Paid, Refunded, Partially Refunded, Voided) states and WooCommerce statuses.
  • Automatic Order Export: Route orders to Shopify in real time or automatically when reaching a specific status (e.g., Processing).
  • Order Financial Control: Include or exclude shipping costs, tax amounts, and discounts on exported orders.
  • Customer Tracking Visibility: Carrier tracking numbers added by vendors in Shopify sync directly to WooCommerce orders and display on customer order screens in My Account → Orders.

Multi-Row Category Mapping

  • Modernized Multi-Row Mapping Interface: Map multiple WooCommerce categories to Shopify collections in a single submission using the + Add another row workflow.
  • Hierarchical Category Selector: Displays full breadcrumb hierarchy paths (e.g. Clothing → Men's → Outerwear) with tree-depth indentation and — Already mapped conflict prevention indicators.
  • Discard Unsaved Mappings Modal: Safety confirmation dialog prevents accidental loss of staged mapping rows.
  • Persistent Mapping Integrity: Mappings are strictly persisted across background queue workers and real-time synchronizations.
  • Searchable mapping list with pagination and bulk deletion.

Webhook Health Diagnostic & HMAC Security

  • Webhook Health Diagnostic & 1-Click Repair: Automatic audit testing active Shopify webhook subscriptions against the site URL with one-click automated repair for broken or missing webhooks.
  • Re-Check Now: Force an instant live audit query against the Shopify Admin API.
  • HMAC SHA-256 Signature Verification: Validates every incoming Shopify webhook payload against the store's private secret key, rejecting spoofed or unauthorized requests.

Real-Time Synchronization & Inventory Control

  • Bidirectional ("Both Ways") Real-Time Sync: Changes made on either Shopify or WooCommerce automatically propagate to the other.
  • Granular Fields to Sync: Multi-select control over which product fields update automatically (Title, Description, Images, Price, Categories, Weight, Barcode, SKU, Inventory, Status, Tags).
  • Real-Time Barcode Synchronization: Direct synchronization of UPC, EAN, ISBN, or alphanumeric barcodes between WooCommerce product meta and Shopify variant barcode fields.
  • Location-Based Stock Sync with Baseline Tracking: Eliminates double inventory deductions during concurrent customer checkouts and background synchronization.

Pricing Rules

  • Define percentage or fixed-amount price increases or decreases applied across customizable price brackets.
  • Apply rules selectively on import, export, or neither.
  • Toggle individual rules on or off without deleting configuration.

Administration & Marketplace Management

  • Single administrative overview of all vendor Shopify connections with live status checks and webhook readiness.
  • Pending background notification queue counter.
  • Full compatibility with WooCommerce High-Performance Order Storage (HPOS), Cart and Checkout Blocks, and PHP 8.4.
