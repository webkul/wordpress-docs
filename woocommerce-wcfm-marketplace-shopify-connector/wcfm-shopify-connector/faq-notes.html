FAQ & Notes

Answers to common questions and practical troubleshooting steps based on verified connector functionality.

Connecting & Setup

Which app type should I use — Dev Dashboard or Legacy?

Use a Developer Dashboard app (OAuth). Shopify discontinued support for creating new legacy custom apps on 1 January 2026. Existing legacy apps keep working, but all new setups should use OAuth 2.0.

Why is my connection refused with a store-name error?

The Store Name you enter must match your Shopify store identifier exactly. If it does not, you will see Added store name does not match with the shopify store name. Copy the name directly from your Shopify store URL.

I get "OAuth Authentication Failed" even though my keys are right.

Check the redirect URIs. Both URIs shown on the credentials step must be added to your Shopify app under Settings → Allowed Redirection URLs, exactly as given. Use Copy Setup URI and Copy Main URI rather than typing them manually.

Why do I see a warning banner about missing OAuth scopes, and how do I fix it?

The connector integrates with Shopify GraphQL Admin API version 2026-10 and requires specific permissions to operate reliably, including catalog, order, inventory, location, and publication scopes (read_products, write_products, read_files, write_files, read_orders, write_orders, read_inventory, write_inventory, read_locations, read_publications, write_publications).

If an essential scope is not enabled in your Shopify app configuration, a yellow warning banner appears on the Manage Account page:

Notice: Connected to Shopify, but your app is missing recommended API scopes: [missing scopes]. Some features may not work properly.

How to resolve it:

  1. Select the Configure Scopes on Shopify → link displayed in the banner (or log into your Shopify Partners or Developer Dashboard, select your app, and navigate to Configuration → Admin API access scopes).
  2. Check the boxes to enable the missing scopes reported by the notice.
  3. Save your changes and release or install the updated app version on your Shopify store.
  4. Refresh the Manage Account page in WCFM. The warning banner will automatically dismiss once all required scopes are active.

Can one vendor connect more than one Shopify store?

Yes, with no fixed limit. Each store maintains its own independent settings, category mappings, price rules, and webhooks. Switch between connected stores using the account switcher at the top right of the screen.

Products & Listings

Can I customize product titles, prices, or images for Shopify without altering my WooCommerce store?

Yes! The connector includes a dedicated Edit Shopify Listing screen. Accessible directly from the product table, it lets you set custom titles, descriptions, override prices, compare-at prices, barcodes, variation images, and custom Shopify galleries with drag-and-drop ordering without modifying your core WooCommerce catalog.

Can I synchronize products bidirectionally?

Yes! Set Product Auto-Sync to Both ways in General Settings. Any edits made in WooCommerce will push to Shopify, and any updates made in Shopify will sync down to WooCommerce. You can also specify exactly which fields sync using the Fields to Sync multi-select controls.

How do I prevent duplicate products if my items already exist on both platforms?

In General Settings, configure Prevent Duplicate Products:

  • Export: Set to Update product if SKU exist and product not synced.
  • Import: Set to Update product if SKU exist and product not synced.

When a matching SKU is detected during an import or export operation, the connector links and updates the existing item rather than creating a duplicate listing.

[!IMPORTANT] SKUs Must Match Exactly on Both Platforms For Prevent Duplicate Products to link and update existing items, the SKU must be exactly identical on both WooCommerce and Shopify. If an item lacks an SKU or if the SKUs differ in casing or spacing, a new product is created instead.

Do I need to keep my browser window open during large imports or exports?

No! Bulk imports, exports, and image downloads process asynchronously using WordPress Action Scheduler. You can safely navigate to other pages or close your browser; the background workers continue processing. Progress is displayed in the Queue Card.

Can I exclude certain products from exporting to Shopify?

Yes. You can toggle the Exclusion Switch icon directly on any row in the product tables, or go to Settings → Exclude Products to search and add WooCommerce products to the master exclusion list via AJAX search.

How do I refresh remote Shopify changes for all mapped products on demand?

Select Refresh Products in the Product Import tab. The connector verifies your mapped catalog against Shopify's latest data and updates titles, prices, barcodes, and inventory in the background.

Orders & Fulfillments

What status will imported orders have in WooCommerce?

Newly imported orders inherit the status mapped under Settings → Order Status Mapping based on their Shopify fulfillment and financial status. If no mapping is configured, they receive the default status set in Import Orders As.

Can WooCommerce orders export to Shopify automatically?

Yes. In General Settings, set Shopify Export Order to Realtime (to export immediately upon order creation) or to a specific status like Processing. Orders will export automatically when entering that status.

Does fulfillment tracking sync back to WooCommerce customers?

Yes. When a vendor marks an exported order as fulfilled in Shopify and enters a tracking number and carrier, the ORDERS_UPDATED webhook captures the event and writes the tracking information to the WooCommerce order, where it is visible to the customer in My Account → Orders.

Category Mapping

Can I map multiple categories at once?

Yes. The Map Categories tab features a multi-row interface. Select + Add another row to stage multiple category-to-collection mappings, then select Save Mappings to commit them in a single batch.

Why are some WooCommerce categories disabled in the mapping dropdown?

The hierarchical category selector disables categories that are already mapped to the active Shopify store (flagged with — Already mapped) to prevent conflicting duplicate assignments.

Webhooks & Security

Why isn't real-time sync working?

Real-time sync requires active webhooks. Open Settings → Webhooks and inspect the Webhook Health Diagnostic card:

  • If the card shows Action Required, select 1-Click Repair Webhooks to re-register missing subscriptions.
  • Ensure Product Auto-Sync is not set to Disable.
  • Confirm that the attributes you want to sync are selected under Fields to Sync.

How are incoming Shopify webhooks secured?

All incoming webhook requests are authenticated using HMAC SHA-256 cryptographic signatures matched against your private Shopify API Secret Key. Any request with an invalid or spoofed signature is rejected immediately with HTTP 401.

Administration

Can the marketplace administrator manage vendor settings?

No. The admin screen (Webkul WC Addons → WCFM Shopify Connector) provides administrative oversight, showing connection health, webhook readiness, and pending webhook queue depth across all vendors. Operations and settings are managed by vendors under their own Shopify credentials.

Getting Help

If you encounter any behavior not covered here, open a support ticket with Webkul Support. Include your plugin version (4.0.0), your WordPress and WooCommerce versions, and any error message displayed in the Queue Card or Webhook Diagnostic.
