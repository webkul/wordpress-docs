Import Orders

Importing brings customer orders placed on your Shopify storefront into WooCommerce, enabling marketplace vendors to manage all customer fulfillment, packing, and sales tracking directly from the WCFM vendor dashboard.

Open Manage Account → Orders → Import Order.

Order Import Settings & Sync Rules

Before importing orders, verify your synchronization preferences under Manage Account → Settings:

SettingLocationAvailable OptionsHow It Works
Auto Import Order (Realtime)General SettingsEnable · DisableWhen enabled, newly placed Shopify orders import into WooCommerce automatically via webhooks the instant the customer finishes checkout.
Order Updates from ShopifyGeneral SettingsEnable · DisableWhen enabled, subsequent changes in Shopify (cancellations, payment updates, customer address edits) automatically update the mapped WooCommerce order.
Imported Order Status SyncGeneral SettingsEnable · DisableWhen enabled, status and fulfillment actions taken on imported orders in WCFM (such as marking an order Completed) automatically push back upstream to Shopify.
Import Orders AsGeneral SettingsRegistered WooCommerce statusesDefault fallback status assigned to newly imported orders before custom status rules execute.
Order Status MappingOrder Status Mapping tabCustom status matrixTranslates Shopify fulfillment states (Fulfilled, Unfulfilled, Partially Fulfilled) and financial states (Paid, Pending, Authorized, Refunded) into specific WooCommerce order statuses.

Two-Stage Order Import Workflow

To ensure accurate line-item and inventory mapping, order imports follow a reliable two-stage process:

Stage 1: Import Order (Fetch & Discover)

Select Import Order. The connector queries the Shopify Admin API for orders containing your vendor products. Orders are validated, mapped against local catalog records, and placed into the staging cache.

Stage 2: Create Imported Orders

The Create Imported Orders (N) button displays the total number of staged orders awaiting database creation (e.g., Create Imported Orders (33)). Selecting this button dispatches the creation jobs to the background Action Scheduler queue.

[!NOTE] Queue-Based Execution: Order creation runs in the background. You do not need to wait on the page while dozens or hundreds of orders process. The queue continues processing automatically.

Interactive Order Queue Card

When an order import run is active, the Order Queue Card displays live progress:

  • Progress Bar: Real-time indicator showing successful, failed, and skipped orders.
  • Live Counters:
    • Queued / Processing: Orders currently queued or being inserted.
    • Imported / Success: Orders successfully created in WooCommerce.
    • Skipped: Orders whose line items do not correspond to any known WooCommerce product are marked Skipped (Missing Product). (Import the products first from the Import Products tab, then retry).
    • Failed: Orders rejected due to currency mismatch or database validation errors.
  • Run Controls:
    • Retry failed (N): Retries only the orders that failed without duplicating processed orders.
    • Cancel (N): Stops active background order processing.
    • Clear run history: Cleans up completed queue run records.

The Imported Order List

All successfully imported orders are displayed in the responsive table:

ColumnInformation Displayed
Store Order IDThe local WooCommerce order ID generated for this sale. Clicking it opens the full WCFM order details page.
Order StatusModern status badge reflecting the current WooCommerce order status (e.g., Processing, Completed, On Hold).
Order Creation DateDate and time when the order was originally placed on Shopify.
Shopify Order IDNumeric Shopify order identifier with a direct link to the order in the Shopify Admin.
Shopify Order NumberPublic-facing Shopify order number (e.g., #1024).

Search & Management

  • Search by Shopify Order ID or Order Number to locate specific transactions.
  • Use the per-page dropdown to display 10, 20, 50, or 100 rows.
  • Select orders and choose Delete under Bulk actions to remove connector synchronization records (this does not delete orders from Shopify or WooCommerce).

Integrated Marketplace Workflow

Imported orders integrate seamlessly into WCFM Marketplace:

  • Line items are assigned to the correct vendor automatically.
  • Marketplace commission splits and vendor earnings calculate using normal WCFM commission rules.
  • Customer shipping addresses, billing info, discounts, and line-item taxes are fully preserved.
