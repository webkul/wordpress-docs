## How it works

<ol class="feature-steps feature--ai">
  <li>
    <span class="feature-steps__title">You set it up</span>
    Connect an AI provider, switch Generative AI on for sellers, and choose the model, the limits and the fields it may fill.
  </li>
  <li>
    <span class="feature-steps__title">The seller describes the product</span>
    On their product's edit page, the seller clicks <strong>Generate with AI</strong>, writes what they sell and can attach photos.
  </li>
  <li>
    <span class="feature-steps__title">The seller decides</span>
    Each suggestion is shown next to the current value. The seller keeps the ones they want, applies them to the form and saves the product.
  </li>
</ol>

## Who uses it

- **Admins** set it up under **WooCommerce Marketplace >> Settings >> Generative AI** and control it per seller on the seller's record. See [Usage Limits](https://wpdoc.webkul.com/woocommerce-marketplace/documentation/usage-limits.html) and [Product Settings](https://wpdoc.webkul.com/woocommerce-marketplace/documentation/product-settings.html).
- **Sellers** use it on the edit page of the products they own, in the Seller Panel. Team members need the **Generate Content With Magic AI** permission in their role. See [Vendor Staff](https://wpdoc.webkul.com/woocommerce-marketplace/documentation/vendor-staff.html).
- **Customers** don't see it. They see the product once the seller has saved it and, if required, you have approved it.

## What it does not do

Generative AI fills in the product form when the seller asks for it, and stops there:

- **It doesn't save, submit or publish a product**, and it doesn't change stock or approval.
- **It doesn't create fake images**. Photos the seller attaches can be added to the product as they are.
- **It isn't available when a seller sells an existing catalog product** via *Select & Sell* or uses bulk upload.
- **It doesn't act on its own**. Each suggestion comes from one request the seller explicitly starts.

::: warning Note on Model Accuracy
AI models can occasionally hallucinate details. Sellers should always verify technical specifications, sizing, warranties, and prices before applying and saving suggestions.
:::

## Generative AI in the rest of your store

The marketplace's Magic AI foundation integrates seamlessly with broader WordPress and WooCommerce AI capabilities:

- **Admin Catalog Moderation**: Platform administrators can run Magic AI to polish product titles, enhance descriptions, or generate missing specifications during product review before approval.
- **WordPress Ecosystem Compatibility**: Built using native WordPress transients and background processing, letting store owners integrate smoothly without site slowdowns.
- **Zero-Cost Self-Hosted AI via Ollama**: Run private, open-weight models (such as Llama 3 or Mistral) on your own server with 100% data privacy and zero API token billing.
