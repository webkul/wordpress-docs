# Introduction

The **WooCommerce Multi Vendor Marketplace plugin** is a powerful solution designed to transform a standard WooCommerce store into a fully functional multi-vendor marketplace.

With this plugin, you can allow **multiple independent vendors** to register, create their own shops, upload products, manage orders, and track earnings – all from a dedicated vendor dashboard.

This enables you to build marketplaces similar to:

- Amazon
- Flipkart
- Etsy
- eBay

## What does this plugin do?

This plugin converts your WooCommerce store into a **multi-seller platform** where:

- Each vendor gets a **separate profile page**
- Vendors can **add & manage products**
- Vendors can **generate content with AI**
- Vendors can **process orders**
- Vendors can **track sales & transactions**
- Vendors can **communicate with admin**
- Admin has **full control over marketplace**
- Vendors get a **dedicated seller dashboard**
- Vendors can **sell existing catalog items**
- Vendors can offer **store pickup with OTP**
- Vendors can **schedule carrier deliveries**
- Vendors can **manage inventory & prices inline**
- Vendors can **add staff accounts**
- Vendors can **set store hours & vacations**
- Vendors can **monitor account health**
- Vendors can **engage shop followers**

## Vendor Capabilities

Once registered, vendors get access to a **frontend dashboard** where they can:

- Add new products
- Edit existing products
- Delete products
- View product listings
- Track sales performance
- View transactions
- Manage orders
- Print invoices
- Update profile information
- Change passwords
- Ask questions to admin
- Generate content with AI
- Enhance images with AI
- Sell existing catalog products
- Generate & print barcodes
- Import products via CSV
- Update stock inline
- Schedule sale prices
- Schedule carrier shipments
- Verify pickup OTP codes
- Request order payouts
- Check account health
- Set store hours
- Schedule vacation mode
- Manage vendor staff
- Reach shop followers
- Switch dashboard views

---

## Admin Capabilities

Marketplace owners (admins) can:

- Manage vendor list
- Manage product list
- Approve or disapprove vendors
- Approve or disapprove vendor products
- Assign products to vendors
- Set **different commission rates** for each vendor
- Enable or disable **auto vendor approval**
- Enable or disable **auto product publish**
- Control all marketplace settings
- Enable separate seller dashboard
- Configure AI providers & vendor quotas
- Set global products for Select & Sell
- Review and approve seller offers
- Configure Store Pickup & OTP rules
- Manage approved fulfillment carriers
- Process vendor payout requests
- Set minimum withdrawal amounts
- Verify vendor KYC documents
- Monitor seller account health
- Track vendors on vacation
- Customize marketplace URL endpoints
