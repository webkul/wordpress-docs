WooCommerce Point of Sale - Installation & Setup Guide

Prerequisites

Essential Requirements

Before installation, ensure you have:

RequirementSpecification
WordPressVersion 6.5 or higher (tested up to 7.0)
WooCommerceVersion 9.1 or higher (tested up to 10.9)
PHPVersion 7.4 or higher (tested up to 8.4)
MySQL5.6+ or MariaDB 10.1+
Memory LimitMinimum 256MB (512MB recommended)
WooCommerce SetupProducts, payment gateways, and shipping configured
User PermissionsAdministrator access to WordPress

Server Requirements

  • SSL Certificate: Recommended for secure transactions
  • Cron Job Access: For scheduled synchronization
  • Node.js: Version 14+ (for full WhatsApp/Node features)
  • File Permissions: Write access to WordPress directories
  • API Access: REST API must be enabled

What You'll Need

  • Purchase Code from Webkul
  • WooCommerce Store with products
  • Admin Credentials for WordPress
  • Barcode Scanner (optional but recommended)
  • Thermal Printer (optional for receipts)

Step-by-Step Installation

Method 1: WordPress Admin Dashboard (Recommended)

Step 1: Access Plugin Installation

  1. Log in to your WordPress Admin Panel
  2. Navigate to: Plugins → Add New
  3. Click "Upload Plugin" button at top

Step 2: Upload the Plugin

  1. Click "Choose File" button
  2. Select the downloaded woo-point-of-sale.zip file
  3. Click "Install Now"

Step 3: Activate the Plugin

  1. After successful installation, click "Activate Plugin"
  2. Wait for activation confirmation message

Check how to activate your WooCommerce plugin through the purchase code.

Method 2: FTP Installation (Alternative)

Step 1: Prepare Files

  1. Unzip the downloaded package
  2. Extract the woo-point-of-sale folder

Step 2: Upload via FTP

  1. Connect to your server via FTP/SFTP
  2. Navigate to: /wp-content/plugins/
  3. Upload the woo-point-of-sale folder

Step 3: Activate

  1. Go to WordPress Admin → Plugins
  2. Find "WooCommerce Point of Sale"
  3. Click "Activate"

Post-Installation Checks

  • Clear WordPress cache if using caching plugins
  • Check for PHP errors in debug log
  • Verify plugin appears in installed plugins list
  • Ensure no conflicts with other plugins

Initial Configuration

The POS Wizard

Until the setup wizard has been completed, opening any Point of Sale admin page takes you to it. To open it again later, go to Point of Sale → Settings and click Help in the top-right corner. Open the Point of sale Setup wizard tab and click the Setup wizard button, as shown in the image below.

Setup Wizard

The wizard has five steps, shown along the top: Begin Wizard → General Settings → Web App Settings → Default Customer → Ready.

Initially, the admin will see the Begin Wizard step. To start configuring the POS, the admin needs to click on Let’s go!.

General Settings Configuration

Clicking on Let’s go! navigates the admin to the General Settings page, as shown in the image below. For more details, you can refer to our User Guide and the Quick Initial Setup video tutorial.

Under General Settings, the admin needs to configure the following:

  • App Connection Password — the password the POS mobile app uses to connect (a random one is suggested)
  • Select Inventory Type — Centralized Stock Inventory or Master Stock Inventory

After filling in the details, click on Next to proceed to the next step.

Web App Settings

Next, the admin needs to configure the Web App Settings, where the following details are added:

  • Name
  • Short Name
  • Theme Color
  • Background Color

Click Next to open the Default Customer step. Its fields — User Name, Email, Password and Telephone — are pre-filled for the default POS customer; review them and click Next to save the wizard, as shown in the image below.

Wizard Completion

Finally, the admin reaches the Ready to Go screen. From here, the admin can:

  • Create a outlet
  • Import outlets from a CSV file
  • Visit Dashboard or Review Settings

Once these steps are completed, the POS Wizard setup is finished.

License Activation

Activation Process

Step 1: Locate Purchase Code

  • Find purchase code in your Webkul purchase email
  • Or access from Webkul client area

Step 2: Enter License Details

  1. Navigate to: Point of Sale → License (its own menu item, not a Settings tab)
  2. Enter your Purchase Code in the plugin's row
  3. Click Activate

Step 3: Verify Activation

  • The Status column shows Approved once the code is accepted
  • Support Till shows the date your support period ends

License Management

  • View License: The License page lists the plugin, its version, where it was purchased (Purchase From), the purchase code, status and support date
  • Extend Support: Shown when support has expired, to renew it
  • Sync Support: Refreshes the support date after you have extended it

Essential Settings to Configure:

1. Permalink Flush

  1. Go to: Settings → Permalinks
  2. Click "Save Changes" (no changes needed)
  3. This ensures POS endpoints work correctly

2. General Configuration

Configure basic connection and branding for the Point of Sale system under Point of Sale → Settings → General → General Configurations.

Configuration SettingDefault / Sample ValueDescription
App Connection PasswordEmpty (set in the setup wizard)Used to authenticate the API connection between the WooCommerce store and the POS mobile app. Keep it private and clear it once the app is connected.
Generate New PasswordAction ButtonGenerates a new password for the API connection (recommended to clear/change periodically).
POS Heading LoginWooCommerce POS SystemDefines the heading text displayed on the front-end POS login screen.
Brand name for footer sectionWebkulSpecifies the brand name displayed in the footer of the POS login page.
Brand Link for footer sectionhttps://webkul.com/Sets the clickable URL linked to the brand name in the footer section.
Invoice LogoLinkThe logo upload has moved to Point of Sale → Settings → Invoice Printer; this row now links there. See Invoice Printer.

3. POS Panel Configurations

Configure operational logic, cashier capabilities, and interface defaults for the POS grid.

Configuration SettingDefault StateDescription
Select Inventory TypeCentralized Stock InventoryDefines if the POS utilizes unified centralized stock levels or separate local inventories.
Default Product Status for OutletEnabledSets whether newly created products are enabled in all outlets by default.
Enable Multi PricingDisabledShows multi-pricing fields on admin products and lets the cashier pick a price on the POS.
Enable zero price productsDisabledAllows selling products with a price of $0.00 in the POS interface.
Show Out of Stock ProductsDisabledOut-of-stock products are always sent to the POS. Enable to show them with an Out of stock badge, disable to hide them. They cannot be sold either way.
Enable Unit Price FeatureEnabledEnables displaying and calculating pricing based on unit quantities (e.g. weight, volume).
Opening Amount Drawer StatusEnabledPrompts cashiers to enter the starting cash drawer balance at the beginning of their shift.
POS Invoice OptionEnabledLets POS users print invoices from the POS. When disabled, invoices cannot be printed at the till.
Enable Mails at POS endEnabledSends order emails to customers and the admin after a POS order is placed. When disabled, no emails are sent for POS orders.
Enable Keyboard ShortcutsEnabledActivates key bindings (shortcuts) for rapid checkout operations.
Enable POS Logo to POS screen headerDisabledDisplays the custom store/POS logo in the main header of the cashier panel. When disabled, the header shows only the user name.
Order status change permissionEnabledAuthorizes POS cashiers to change the status of orders directly from the POS interface.

POS Cron Configurations

Here, the admin can configure and manage POS cron jobs (Point of Sale → Settings → General → POS Cron Configurations). For every field see POS Cron Configurations.

POS Cron Settings

The admin can:

  • Set the Cron Type Choose between Server Cron (Recommended) (default) or WP Cron.

  • Enable / Disable Auto Drawer Close Turn automatic drawer closing on or off.

  • Set Drawer Time Define the time after which the drawer will close automatically.

  • Run Cron Commands With Server Cron selected, the tab shows the exact Server cron commands for your site; add one of them to your server's crontab.

Server Cron Setup

For Server Cron

Example (replace the address with your own site URL, or copy the command shown on the settings tab):

wget -q -O - https://wpdemo.webkul.com/woocommerce-point-of-sale-115-113-191-18/wp-content/plugins/woo-point-of-sale/wcpos-cron.php >/dev/null 2>&1
