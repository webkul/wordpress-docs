WooCommerce POS - Admin Configuration & Settings Guide

POS Configurations Performed by the Admin

The POS system provides multiple configuration options that allow the admin to control inventory warnings, order behavior, customer management, payments, appearance, and more. Below is a detailed overview of all available configurations.

All of them live under Point of Sale → Settings, split into these tabs: General, Customer, Payment, Invoice Printer, Printing, Appearance, Endpoints and Custom CSS & JS. A POS Mass Assign tab is added when it applies to your inventory setup, a Node Server tab when the Node server is enabled, and the WhatsApp module adds API Configuration.

Sections of the General tab

The General tab is one long form, saved with Save Configurations. Its sections appear in this order: General Configurations, POS Panel Configurations, POS Audio Configurations, POS Cron Configurations, Order & Stock Configurations, the WhatsApp settings (when the WhatsApp module is active), Barcode Settings, Web APP Settings and Media Settings. General Configurations and POS Panel Configurations are described in the Installation & Setup guide.

POS Audio Configurations

Controls the sounds the till plays. Tones are off by default.

SettingDescription
Enable tones on pos endEnable / Disable (default Disable). Turns audio tones on the till on or off for every outlet.
Add Custom ToneOpens a dialog to add your own sound: enter a Tone Name, paste a Tone URL or pick a file with Upload File, then click Save Tone. Custom tones are offered alongside the built-in ones.

Each outlet can override the store setting with its Tones on pos end field (Use Global Setting / Enable / Disable) and pick its own default tones — see Outlet form fields.

Only when tones are enabled does the till show Settings → Audio Settings, where the cashier can switch Audio on or off and choose the Keypad Tone, Product Tone and Out of Stock Product Tone.

POS Cron Configurations

These settings help administrators manage cash drawer lifecycle operations and automatic reports.

Configuration SettingDescription
Cron TypeServer Cron (Recommended) (default) or WP Cron. With Server Cron the tab shows the Server cron commands to add to your server's crontab. WP Cron needs no setup but only runs when someone loads a page, so scheduled tasks can be missed.
Auto Drawer closeEnable or disable automatic closing of the POS drawer (default Disabled).
Drawer Auto Close timeSet the time at which the drawer will automatically close (e.g., 12:00 AM). Times are offered in 15-minute steps.
Drawer Close EmailEnable to receive an email when a drawer is closed (default Disabled).
Drawer Close TypeOrders ( Deprecate Soon ) (default) or Transactions ( Recommended ) — what the drawer close is calculated from. The Orders option will be removed in an upcoming version, so choose Transactions.

Order & Stock Configurations

Configure stock warnings, order-handling rules, offline synchronization, and billing behavior.

Configuration SettingDescription
Quantity For Low Stock WarningProducts at or below this quantity show a low stock warning on the till.
Amount you want to increase after roundoffDefine the amount (default 5) offered as the round-off step in the POS custom payment option.
Auto Sync Offline OrdersEnable to automatically sync offline POS orders once the internet connection is restored.
Load WooCommerce OrdersEnable or disable syncing of general online WooCommerce orders to POS outlets (default Disable).
Order Id PrefixEnter a custom prefix to be prepended to POS order IDs for distinct sales tracking (e.g. POS_ shows order 470 as #POS_470).

WhatsApp Greetings Settings

Configure how automated customer receipts and greetings are sent via WhatsApp. This section is added to the General tab by the WhatsApp module, right after Order & Stock Configurations.

Setting NameDescription
Send Whatsapp message to clientEnable to allow sending WhatsApp messages directly from the POS interface.
Send Order receipt to clientEnable to send the order receipt message to the customer via WhatsApp.
Send Automatic Order receipt to clientEnable automatic dispatch of order receipts via WhatsApp immediately upon transaction completion.
Send message to multiple clientsEnable to authorize broadcasting messages to multiple selected customers.

Barcode Settings

Customize the visual output and formatting of product barcode labels.

Setting NameDescription
Background ColorSelect the background color for the barcode label (default #ffffff).
WidthDefine the horizontal width/thickness of the barcode lines (default 0.8).
Display TitleEnable to show the product title/name on the barcode label.
HeightSet the vertical height of the barcode (default 20).
Text PositionChoose the position of the barcode text (e.g., Top or Bottom).
Text SizeDefine the size of the title and custom text printed with the barcode (default 14).
Print PreviewThe page orientation the barcode print preview uses: Portrait or Landscape.

Customer Details

The Customer tab holds the details of the default POS customer created by the setup wizard. Below are the configurable fields:

  • First Name First name of the default customer.

  • Last Name Last name of the default customer.

  • Email Email address of the default customer.

  • Password The default password for customers that are added from the POS panel. Enter your own strong password; it is stored securely and never shown in plain text.

  • Telephone Phone number of the default customer.

Customer Address

  • Company Enter the customer's company name (if applicable).

  • Address1 Primary street address.

  • Address2 Secondary street address (optional).

  • City Customer's city.

  • Postcode Customer's postal code.

  • Country Customer's country.

Payment Methods

Admins can configure payment methods for record-keeping and checkout purposes.

  • Click the Add New button to create a payment method.

  • Admin can Edit or Delete existing payment methods.

  • Enter the following details:

    • Payment Name
    • Payment Slug
    • Payment Description

  • Enable or disable payment methods as required.

  • The added payment method must be selected in the respective outlet to be usable.

Invoice Printer

Go to Point of Sale → Settings → Invoice Printer. The Invoice page size section sets the paper used when receipts are printed.

SettingDescription
Select Default Printer TypeA4 Page (default) / A3 Page / Epson TM-T88V Thermal Page / A5 Page / A6 Page.
Thermal Roll Width (mm)Width of the paper roll, 20–210 mm (default 58). Shown only when Epson TM-T88V Thermal Page is selected.
Thermal Roll Height (mm)Length each printed page is cut at, 20–1000 mm (default 120). Raise it to keep a long receipt on one page. Shown only for Epson TM-T88V Thermal Page.
Invoice LogoUpload the logo printed on invoices and receipts. (It used to be on the General tab and has moved here.)

Cashiers can set the same roll width and height for their own till under Settings → Other Settings when Select Invoice Page size is the Epson TM-T88V thermal page.

Invoice Template Fonts

Navigation path:Point of Sale → Invoice Templates → Edit → Editor

Since version 7.3.0, the invoice template builder lets you choose the typeface of your receipts.

One Font for the Whole Invoice

Click Default Settings (next to + and Reset Default). In the panel that opens, choose a Font Family. It applies to every field that has no font of its own.

A Font for One Field

Click a field on the invoice to open its properties, then choose its Font Family. A font set on a field takes priority over the default font.

OptionResult
DefaultThe field keeps the invoice's standard type (or the default font, when one is set).
Arial, Courier New, Georgia, Helvetica, Tahoma, Times New Roman, Trebuchet MS, VerdanaFonts installed on practically every computer.
Custom FontType a font name, for example Roboto. A font the till does not have is loaded as a web font so the receipt prints in it.

Save the template to keep the change; every receipt printed from that template uses it.

Fonts and direct printing

Invoice fonts are used when receipts print through the browser print dialog. Receipts sent through Direct Printing use the thermal printer's own type.

Printing

New in 7.3.0, Point of Sale → Settings → Printing sends receipts, drawer reports, barcode labels and PDFs straight to a printer on your counter through an external print service, instead of opening the browser print dialog. The printers are reached through a small app on the till computer, so they do not need to be attached to your web server.

SectionWhat you set
Print servicePrint service (Disable by default / Enable) and the API key from your print service account (use the Create a key link). The key is checked when you save and your printers are loaded; Refresh printers reloads the list.
Thermal printerThe receipt printer (or Not used) and Thermal printer width (characters), 16–170, default 48 for 80 mm paper (32 for 58 mm).
ZPL printerThe label printer for barcode labels, with Label width (dots) (default 450) and Label height (dots) (default 210).
PDF printingA PDF printer for sending PDF files from the media library.

Each outlet can use its own thermal printer, and cashiers can pick one for their session from the till header. For setup steps, priorities and error messages see Direct Printing.

Appearance Settings

Personalize theme elements, product image shapes, and layout styles across the cashier terminal.

Visual ConfigurationOptions / ChoicesDescription
POS Theme ModeOS Default Mode (default) / Light Mode / Dark ModeChoose the default theme style for the POS terminal.
Color SchemesDropdown SelectSelect from predefined color schemes or customize manually.
Primary Color / Secondary Color / Primary Light Color#FC8019 / #09AA29 / #f7e1c9 (defaults)Custom POS colors. Reset to Default restores them.
Category UIOld style / New style (default)Choose the visual layout style for product categories.
POS Product Image ViewCircle (default) / Square / RoundedSet the shape style of product images on the catalog grid.
Payment Method ListingGrid View Listing (default) / Grid With Currency Listing / Dropdown ListingSelect the layout style of payment methods at checkout.
Product Variations ViewList View (default) / Table View / Card ViewStyle of the variation popup on the till.
Cart & Pay Page Product Image DisplayEnabled (default) / DisabledShow or hide product images on the cart and pay page.
Cart Total Section DisplayExpanded (default) / CollapsedExpand the cart total section by default or collapse it — see Cart Totals & Item Editing.
Submit Button on Item ExpandDisabled (default) / EnabledShow a Submit button when an item in the cart list is expanded.
Newest Cart Item FirstDisabled (default) / EnabledShow the item added to the cart last at the top of the cart list.

The dark-mode switch in the till header is a per-session toggle for the cashier; it does not change the admin setting above.

Endpoints

Point of Sale → Settings → Endpoints sets the Endpoint — the URL slug the POS opens at (default pos, e.g. yoursite.com/pos). After changing it, open Settings → Permalinks and click Save Changes once so the new address works.

Custom CSS & JS

Point of Sale → Settings → Custom CSS & JS has two code editors, Custom CSS and Custom JS, for adding your own styling or scripts to the POS screen. Click Save to apply.

POS Mass Assign

Point of Sale → Settings → POS Mass Assign gives every product the same POS stock in every outlet in one step: enter the quantity in Enter Quantity and click Bulk Assign. For example, with 100 in stock and two outlets, entering 50 assigns 50 to each outlet while the store stock stays 100. The tab is hidden when your setup forces centralized inventory.

Module Translation

Admins can translate the POS module into different languages.

  1. Save the translation file in the WordPress languages directory.
  2. Run the following command:
wp i18n make-json wc_pos-xx_YY.po --no-purge

WPML

Since version 7.1.0 the POS works with WPML. There is no extra settings screen:

  • The POS Heading Login, footer brand name and link, and the web-app Name and Short Name can be translated in WPML → String Translation.
  • Products and categories shown on the till follow the active WPML language.
  • The outlet, order note and cashier recorded on a POS order are kept on its translated copies.
