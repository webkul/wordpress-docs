Z-Report Generation & Printing

Introduction

A Z-Report is a vital audit document that summarizes all sales transactions, payment methods, and cash reconciliations when closing out a POS register shift. WooCommerce Point of Sale (POS) includes a built-in Z-Report generation tool that allows store staff and administrators to audit daily sales, calculate cash drawer variances, and print physical summaries.

This page guides you through the step-by-step workflow for register closure, printing, and administrative reconciliation.

Step-by-Step Workflow

Section 1: Drawer Reports from POS

POS cashier agents can inspect their active drawer statistics before closing out their shifts. To access the active drawer summary:

  1. Open the POS register interface.
  2. Click on the Cashier tab in the side navigation menu.
  3. The Close Counter tab opens with the Drawer Account Summary.
  4. Review the Opening Amount, Expected Amount in Drawer, Difference, and the per-payment-mode Paid, Change, Refund, and Total figures.
  5. To print a mid-shift snapshot without closing the drawer, click Print Drawer Report. The report is saved with the type Print and sent to the printer straight away.

The other Cashier tabs are Today Cash (or Today Transactions, depending on the Drawer Close Type setting), Order History, and Print Drawer Reports.

Section 2: Closing and Printing Drawer Report

When a cashier's shift ends, they must close out the active drawer register and record physical cash tallies:

  1. Navigate to the POS side menu and click Cashier.
  2. On the Close Counter tab, click the Close Drawer button.
  3. The Close Drawer dialog will appear. Cashiers fill out:
    • Expected Cash: Calculated sum of the opening amount and cash taken during the shift (read-only).
    • Actual Cash in Drawer: Input the counted cash physically present in the register.
    • Closing Notes: Add optional closing comments or shift handover remarks.
    • Print closing report: Ticked by default. Leave it ticked to save and print the closing (Z) report; untick it to close the drawer without printing.
  4. Click Close Drawer to lock the shift. The closing report is saved with the type Close, and the variance between expected and actual cash is calculated on the report.

Section 3: Printed Z Report

After confirming the register closure details, the system generates a receipt-friendly print layout and sends it to the printer:

  1. Once the shift is closed, the browser print dialog opens with the report.
  2. The layout follows the register's Select Invoice Page size (Settings > Other Settings). With Epson TM-T88V Thermal Page, the Thermal Roll Width (mm) and Thermal Roll Height (mm) values set the paper size, so it fits 58mm and 80mm rolls alike.
  3. Review the printed totals (opening amount, total sales, payment methods, counted cash, and variance) before finalizing.

Direct printing (7.3.0)

When the print service is enabled under Point of Sale > Settings > Printing and the register's invoice page size is Epson TM-T88V Thermal Page, drawer reports (closing reports, mid-shift reports, and reprints from the POS) print directly on the chosen thermal printer with no browser dialog. If the service cannot print, the browser print dialog opens instead. See Direct Printing.

Section 4: Drawer Reports History at POS

Cashiers can review previously generated reports without leaving the register. The Print Drawer Reports listing was redesigned in version 7.0.0 to match the POS theme and now includes date filtering:

  1. Open the POS side menu and click Cashier.
  2. Switch to the Print Drawer Reports tab to open the Drawer Reports History.
  3. Use the Date Range filter to narrow the archive, then review each entry's Report ID, Type (Print or Close), Print Time, Starting Cash, Expected Cash, Actual Cash, and Variance Cash columns.
  4. Click Reprint in the Actions column to print a past report again when a physical copy is needed.

Reliability improvements in 7.0.0

Drawer report data mismatches, problems when closing the drawer while a report was printing, and transaction totals when another user processes a refund were all fixed in version 7.0.0 — drawer numbers now reconcile consistently across the POS and admin ends.

Section 5: Admin Drawer Report Records

Store managers and administrators can audit drawer shifts centrally from the WordPress dashboard:

  1. Log in to the WordPress Admin Dashboard.
  2. Navigate to Point of Sale > Drawer.
  3. The Drawer List tab opens. When the Drawer Close Type setting is Transactions ( Recommended ), it lists every shift with filters for Select User, Select Start Date, and Select End Date, and these columns:
    • Drawer Managed By
    • Opening Amount
    • Payments
    • Closing Amount
    • Status
    • Opened At & Closed At
    • Opening Note & Closing Note
  4. With the Orders ( Deprecate Soon ) close type, the list instead shows Outlet, Card Amount, Cash Amount, Opening Amount, Closing Amount, Date, and Remark.

Section 6: Print Drawer Reports in the Admin

Every drawer report printed or closed on any register is saved and can be reviewed centrally from the WordPress dashboard:

  1. Navigate to Point of Sale > Drawer in the WordPress admin panel.
  2. Click on the Print Drawer Reports tab.
  3. Narrow the list with the All Cashiers dropdown and the start and end date fields, then click Filter, or use Search Reports.
  4. Review each report's Report No, Type, Cashier, Outlet, Print Time, Starting Cash, Expected Cash, Actual Cash, and Variance Cash.
  5. Click Reprint in the Actions column to print a past report in the receipt layout through the browser print dialog. Reports are printed, not downloaded.

Benefits

The Z-Report framework provides essential auditing benefits for retail stores:

  • Daily Sales Reconciliation: Automatically compiles all cash, card, and digital payment methods, saving cashiers from manual calculation at shift end.
  • Cash Drawer Verification: Instantly calculates the difference between expected registers and physical counted cash to identify register variance.
  • End-of-Day Reporting: Aggregates transaction summaries into clean, printable receipts to keep as physical records.
  • Audit Tracking: Maintains a secure, unalterable digital log of all open/closed register sessions in the database for accounting purposes.
