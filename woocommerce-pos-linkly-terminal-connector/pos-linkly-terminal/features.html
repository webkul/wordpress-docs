Features

For the store owner

  • Linkly card payments on the POS — accept card payments from a Linkly EFTPOS terminal on any WooCommerce POS outlet.
  • Test and live credentials — store separate Linkly test and live usernames and passwords and switch to the Linkly sandbox with the Test mode checkbox.
  • Default POS gateway — make the Linkly terminal the default so the pay screen opens with POS Linkly Reader selected.
  • Per-outlet control — offer Linkly only at outlets that have a terminal, using each outlet's Additional Payment Option list.
  • Enable or disable in one place — turning the gateway off removes the Linkly payment method and the Linkly icon from every POS till.
  • Automatic order status — Linkly orders stay Pending payment until the card is approved, then become Completed; the Linkly transaction details are saved on the order.
  • Multisite ready — the Linkly payment method is created on every site of a multisite network, including sites added later.
  • Partial payment support — works with the WooCommerce POS Partial Payment add-on so installments can be paid on the terminal.

For the cashier

  • Pair with a code — pair a till with a Linkly PIN pad by entering the pair code shown on the terminal; the pairing is remembered for that POS user.
  • Live connection status — each time the POS opens, it checks the saved pairing with Linkly; the dot on the Linkly icon turns green when connected, red when not paired or when the pairing is no longer valid, and grey while checking. See what the status dot means.
  • Re-pair without losing the sale — if Linkly rejects the pairing when a payment starts, the POS asks for a new pair code and Save & pay again sends the same order to the terminal.
  • Guard against unpaired payments — the POS will not start a Linkly payment until the till is paired.
  • Card reader progress screen — a card reader animation shows while the customer pays on the terminal.
  • No double charges — if the terminal is slow, the POS keeps checking the same transaction for up to five minutes, and Pay again resumes an unfinished payment rather than starting a new one.
  • Invoice on approval — the POS invoice prints automatically after an approved payment when invoice printing is enabled.

Cards accepted

The connector hands the payment to your Linkly terminal, so the cards you can accept (for example Visa, Mastercard, American Express, or Discover) are the ones your Linkly terminal and merchant acquirer are set up to accept.
