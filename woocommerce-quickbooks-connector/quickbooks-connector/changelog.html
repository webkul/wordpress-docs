Changelog & Version History

Complete release notes, feature additions, fixes, and optimizations across every release of WooCommerce QuickBooks Connector.

v4.0.0

Latest Release
2026-11-18
  • AddedReal-time bidirectional stock synchronization that automatically updates inventory levels between WooCommerce and QuickBooks Online.
  • AddedGranular field-level sync controls with "Details to Export" and "Details to Import" settings for product attributes.
  • AddedAdvanced Class & Department Mapping tabs with Product Category to Class and Country to Class/Department resolution rules.
  • AddedDedicated QuickBooks Dashboard tab featuring real-time sync KPIs, 7-day activity chart, and financial snapshot widgets.
  • AddedEmbedded QuickBooks Financial Reports tab providing in-admin Profit & Loss, Balance Sheet, Cash Flow, Item Sales, Customer Sales, and A/R Aging.
  • AddedComprehensive Sync Monitor suite with Overview trends, Activity audit trail with raw JSON inspector, and system logs.
  • AddedNative Webkul POS split-payment routing with dedicated clearing account mapping (pos_split).
  • AddedAutomated sync failure email notifications with configurable recipient and digest frequencies.
  • AddedDedicated account mapping settings for positive order fees (income) and negative fee discounts.
  • AddedDynamic fee item naming and description resolution with extensible filter hooks for order and refund sync.
  • AddedAutomatic synchronization of multiple applied coupon codes into QuickBooks transaction PrivateNote memo and discount line descriptions.
  • AddedDynamic multi-select for order auto-export statuses with mutual exclusivity and backward compatibility.
  • AddedExtensible action and filter hooks for transaction fee meta keys, amounts, accounts, and expense/journal entry sync management.
  • AddedBulk Export and Update in QuickBooks actions directly to WooCommerce Orders, Products, and WordPress Users admin tables.
  • AddedPenny-rounding reconciliation setting for QuickBooks invoices and sales receipts.
  • AddedWebhook signature verification (HMAC SHA-256 and Intuit Verifier Token) with dedicated webhook setup card and queue status.
  • ImprovedReplaced legacy WP-Cron background processing with WooCommerce Action Scheduler with 3x retry resilience.
  • ImprovedFull compatibility certified for WooCommerce High-Performance Order Storage (HPOS) and Cart/Checkout Blocks.
  • OptimizedImplemented transient caching for Intuit API accounts and tax codes, reducing API requests by up to 75%.
  • FixedResolved duplicate customer name collision (Error 6240) by appending unique email identifiers during conflict.

v3.0.2

2026-07-25
  • ImprovedEnhanced OAuth 2.0 token refresh error recovery with automated background renewal.
  • FixedCorrected line item rounding discrepancies when exporting orders with multiple tax rates.

v3.0.1

2026-04-10
  • AddedSupport for exporting WooCommerce order custom fee lines to designated QuickBooks Income accounts.
  • FixedResolved tax code lookup failure when store currency differs from default QuickBooks currency.

v3.0.0

2026-01-15
  • AddedBrand new 4-step interactive Setup Wizard guiding merchants from Welcome to Live Connected status.
  • AddedInteractive credential testing tool that validates Intuit Client ID and Secret prior to saving.
  • AddedAutomatic synchronization of customer phone numbers into QuickBooks Customer primary phone field.
  • ImprovedComplete UI modernization with responsive flexbox tables and native WordPress 6.7 design tokens.
  • FixedFixed duplicate customer creation by checking both DisplayName and PrimaryEmailAddr before insert.

v2.2.0

2025-09-20
  • AddedRefund receipt synchronization when orders are partially or fully refunded in WooCommerce.
  • AddedSupport for WooCommerce customer tax exemption status mapping to QuickBooks Out-of-Scope tax code.
  • ImprovedBatch product export now processes up to 100 items per request, cutting initial sync time by 60%.

v2.1.0

2025-05-12
  • AddedMulti-currency support: automatically record transactions in order currency with Intuit exchange rates.
  • AddedConfigurable fallback tax code for line items without explicit tax rules.
  • FixedFixed guest checkout customer mapping when billing email matches an existing registered user.

v2.0.0

2024-12-05
  • AddedMigration to Intuit OAuth 2.0 authentication standard for increased security and long-lived tokens.
  • AddedTwo-way customer synchronization: export WooCommerce customers and import QuickBooks contacts.
  • AddedVariable product sync with individual SKU, price, and attribute matching for each variation.
  • ImprovedRedesigned admin navigation with dedicated tabbed interface for streamlined configuration.

v1.0.6

2024-08-18
  • AddedExport variable products with variation SKU and pricing mapping.
  • AddedExport orders with shipping line items mapped to dedicated QuickBooks shipping items.
  • AddedExport discount and coupon lines accurately on QuickBooks invoices.
  • FixedCorrected listings, pagination, and sorting across Orders, Products, and Customers admin tables.

v1.0.2

2024-05-10
  • AddedWebkul WooCommerce POS integration support.
  • FixedNonce verification and capability security audit across all AJAX actions.

v1.0.0

Initial Release
2024-01-20
  • AddedInitial release of WooCommerce QuickBooks Connector.
  • AddedExport WooCommerce customers to QuickBooks Online.
  • AddedExport WooCommerce simple products to QuickBooks Online.
  • AddedExport WooCommerce orders as QuickBooks invoices and sales receipts.
  • AddedAuto sync inventory increment and decrement on order status changes.
  • AddedPayment method and tax rate mapping configuration.
  • AddedSingle-click QuickBooks connection via Intuit OAuth.
