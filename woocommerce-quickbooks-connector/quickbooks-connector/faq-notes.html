FAQ & Notes

Verified fixes for the situations merchants actually hit, followed by quick answers and support contacts.

Common Troubleshooting

The store shows "Credentials Stored — Re-authorization Needed"

Cause: credentials are saved but the access tokens are missing or no longer valid — this also happens automatically the moment any credential field is edited.

Fix:

  1. Open Webkul WC Addons → WC Quick Book Connector.
  2. Click Connect Again / Edit Credentials.
  3. Click Connect with QuickBooks and approve access — tokens and Company ID are refetched automatically.

"Unable to connect to QuickBooks. Please verify your credentials, Company ID, or authentication tokens."

Cause: the connection test failed against the QuickBooks API.

Fix — check in this order:

  1. Mode matches keys — Sandbox keys only work in Sandbox / Development mode, production keys only in Live / Production.
  2. Client ID / Secret — re-copy both from your Intuit Developer app (watch for trailing spaces).
  3. Redirect URIs — both connector URIs must be registered in the Intuit app exactly as shown on the Connection Settings page.
  4. Re-run the authorization. Your previous working credentials are preserved automatically when a test fails.

"Wrong Credentials used please check the credentials again" during authorization

Cause: the token exchange with Intuit was rejected.

Fix: confirm the Client ID/Secret belong to the app whose redirect URIs you registered, then run Connect with QuickBooks again.

An order didn't export automatically

Check:

  1. Auto Export Orders in Auto Sync Settings — the order must reach the exact status you selected (or use All).
  2. The order contains only zero-price products while Export Orders With Product Price Zero is No in Export Order Settings.
  3. The sync log: WooCommerce → Status → Logs, sources named WooCommerce QuickBook… — every export attempt and its result is recorded there.
  4. Export it manually from the Orders tab — the result (green pill or error) confirms whether the connection works.

A product wasn't exported in real time

Check:

  1. Real-time export is Enabled in Auto Sync Settings.
  2. The product's category is in the selected auto-sync categories (or All is selected) — products outside the list are skipped and the skip is logged.
  3. Zero-price products need Export Products on QuickBooks With Price Zero set to Yes in General Settings.

Products were skipped during Create Products

Cause: the "Products skipped due to duplicate SKU" counter increments when a staged QuickBooks item's SKU already exists in WooCommerce.

Fix: that's duplicate protection working. If the item genuinely is the existing product, map the two on the Products tab instead of re-creating it.

A refund didn't create a refund receipt

Check: Auto Generate Refund Receipt must be Enabled in Auto Sync Settings — when it is disabled the skip is written to the log. Only refunds on orders already exported to QuickBooks can generate receipts.

Account dropdowns are empty in General Settings

Cause: the account lists load live from QuickBooks, so an interrupted connection leaves them empty.

Fix: restore the connection first (Connection Settings), then reload the page.

Frequently Asked Questions

Does the connector change anything on my storefront?

No. It is an admin-only integration — customers see nothing new. The only storefront involvement is invisible: an order placed by a customer can trigger auto export.

Can I test without touching my real books?

Yes. Connect in Sandbox / Development mode against Intuit's free sandbox company, test every flow, then reconnect in Live / Production with your production app keys.

Which order types can QuickBooks receive?

Each exported order becomes a Sales Receipt, Invoice, Estimate, or Credit Memo — one store-wide choice in Export Order Settings.

Are product variations supported?

Yes — a variable product exports each variation as its own QuickBooks item.

Does it work with HPOS (High-Performance Order Storage)?

Yes, the plugin declares compatibility with HPOS and Cart/Checkout Blocks. The QuickBooks status column appears on the HPOS Orders screen too.

Does it recognize POS orders?

When a Webkul POS plugin is active, the Orders tab labels each order's source as POS or WooCommerce and can filter by source.

What happens if I delete my credentials?

The connector forgets the connection and re-opens the Setup Wizard; data already synced to QuickBooks stays in QuickBooks. See Connection Settings.

Where do I see what synced and what failed?

WooCommerce → Status → Logs — the connector writes detailed entries under log sources beginning with WooCommerce QuickBook.

Notes & Limitations

  • One QuickBooks company per store — the connector links to a single Company ID (Realm ID) at a time.
  • Payment records, refunds, and deposits flow to QuickBooks; orders are not imported from QuickBooks into WooCommerce.
  • Real-time and background jobs (webhook processing, scheduled deposits, queue retries) run reliably via WooCommerce Action Scheduler with automatic 3x retries.
  • OAuth 1.0 remains selectable for legacy setups but is deprecated — use OAuth 2.0.

v4.0.0 Capabilities & Troubleshooting

Does the connector support a queue system for high-volume background processing?

Yes. WooCommerce QuickBooks Connector natively leverages WooCommerce Core's Action Scheduler (wp_actionscheduler_actions) queue engine for order synchronization, inventory balancing, and webhook events:

  • Decoupled Asynchronous Processing: Order sync tasks are dispatched asynchronously to the background queue immediately after checkout completes. Customer checkout finishes in milliseconds with zero lag or timeout risks.
  • Automatic 3x Retries with Exponential Backoff: Temporary network dropouts (HTTP 502/503), rate limit throttles (HTTP 429), or gateway timeouts (HTTP 504) are automatically rescheduled 3 times with exponential backoff delays.
  • Quarantine & Needs Attention Isolation: Persistent failures are safely isolated into the Needs Attention table on the Dashboard (tab=dashboard), preventing stalled sync tasks from blocking other queue items.
  • WP-CLI & Crontab Worker Support: High-traffic stores can execute background queues via wp action-scheduler run or server crontab, offloading sync operations entirely from web traffic.

How does two-way stock synchronization avoid infinite loops?

The connector flags the origin of each inventory change. Updates triggered by a WooCommerce order or local edit are flagged during export, so when QuickBooks echoes the change via webhook, the connector recognizes the origin and skips redundant re-exporting.

How are order fees and custom discounts mapped in QuickBooks?

In Export Order Settings → General, you can specify dedicated QuickBooks accounts for Positive Order Fees (shipping surcharges, gift wrapping) and Negative Fee Discounts. If left blank, fees default to your Configured Income Account.

How do Webkul POS split payments record in QuickBooks?

Orders processed with multiple tenders (e.g. cash and card split tenders) are mapped to your designated POS Split Payment clearing bank account. The exact tender breakdown is automatically recorded in the transaction PrivateNote statement memo.

What does Penny-Rounding reconciliation do?

It adds an automated Roundoff Adjustment line item for fractional discrepancies (up to the threshold, default 0.50) caused by item-level vs total-level tax rounding, ensuring QuickBooks accepts the transaction with zero rounding errors.

How does the connector prevent duplicate customer name errors (Error 6240)?

QuickBooks Online requires customer display names to be unique. The connector's disambiguation algorithm matches existing customers by verified email address first. If a name collision occurs without an email match, it appends unique customer identifiers to prevent sync rejection.
